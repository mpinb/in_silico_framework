

run_ex_synapses
===============


.. Signature -------------------------------

.. py:function:: simrun.synaptic_strength_fitting.run_ex_synapses(neuron_param, network_param, celltype, gAMPA=None, gNMDA=None, gGABA=None, vardt=False, tStim=None, tEnd=None, mode='cells')


   Simulate all EPSPs of a given celltype, one by one.

   This function reads the network parameter file, selects one celltype, and activates each synapse of that celltype,
   as defined by their corresponding :ref:`syn_file_format` file. The simulation is reset after each synapse activation run.

   This function is used in the :py:class:`~simrun.synaptic_strength_fitting.PSPs` class to simulate each synapse.

   :param neuron_param: The :ref:`cell_parameters_format`.
   :type neuron_param: ~single_cell_parser.parameters.NTParameterSet
   :param network_param: The :ref:`network_parameters_format`.
   :type network_param: ~single_cell_parser.parameters.NTParameterSet
   :param celltype: The celltype to activate the synapse for. Used to fetch the correct network parameters.
   :type celltype: str
   :param gAMPA: The AMPA conductance value. Default: ``None``.
   :type gAMPA: float
   :param gNMDA: The NMDA conductance value. Default: ``None``.
   :type gNMDA: float
   :param gGABA: The GABA conductance value. Default: ``None``.
   :type gGABA: float
   :param vardt: Whether to use the variable step size solver. Default: ``False``.
   :type vardt: bool
   :param tStim: The time of the synaptic activation. Default: ``None``.
   :type tStim: float
   :param tEnd: The end time of the simulation. Default: ``None``.
   :type tEnd: float
   :param mode: Whether to activate each synapse one by one, or each cell one by one.
                A presynaptic cell may have multiple synaptic connections with the neuron model (i.e. the :py:class:`~single_cell_parser.cell.Cell`).
                Options: ``('cells', 'synapses')``
   :type mode: str

   :returns: A tuple containing the voltage baseline, and voltage traces of all synapses. Format: ``(t_baseline, v_baseline, [t_vecs], [v_vecs])``
   :rtype: tuple

   .. seealso::

      :py:meth:`~simrun.synaptic_strength_fitting.PSPs.run_ex_synapse` for the core function to
      simulate a single synapse.
