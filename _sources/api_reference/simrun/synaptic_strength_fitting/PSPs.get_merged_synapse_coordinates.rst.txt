

get_merged_synapse_coordinates
==============================


.. Signature -------------------------------

.. function:: simrun.synaptic_strength_fitting.PSPs.get_merged_synapse_coordinates(mergestring, flatten=False)


   Get the coordinates of all synapses that contain a certain string in their name.

   :param mergestring: The string to search for in the synapse names.
   :type mergestring: str
   :param flatten: Whether to flatten the list of synapse coordinates. Default: ``False``.
   :type flatten: bool

   :returns: A list of synapse coordinates.
   :rtype: list
