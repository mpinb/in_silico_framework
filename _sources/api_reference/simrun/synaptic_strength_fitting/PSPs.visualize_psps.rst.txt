

visualize_psps
==============


.. Signature -------------------------------

.. function:: simrun.synaptic_strength_fitting.PSPs.visualize_psps(g=1.0, method='dynamic_baseline', merge_celltype_kwargs={}, fig=None)


   Plot a histogram of the EPSP max voltage deflections for each celltype.

   :param g: The simulated synaptic strength value to plot.
   :type g: float
   :param method: ``dynamic_baseline`` or ``constant_baseline``.
   :type method: str
   :param merge_celltype_kwargs: Additional keyword arguments to pass to :py:meth:`~simrun.synaptic_strength_fitting.merge_celltypes`.
   :type merge_celltype_kwargs: dict
   :param fig: A matplotlib figure to plot the histograms on.
   :type fig: plt.Figure

   :returns: None. Plots the histograms.
