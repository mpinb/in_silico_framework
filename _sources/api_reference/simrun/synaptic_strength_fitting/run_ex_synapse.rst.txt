

run_ex_synapse
==============


.. Signature -------------------------------

.. py:function:: simrun.synaptic_strength_fitting.run_ex_synapse(cell_nw_generator, neuron_param, network_param, celltype, preSynCellID, gAMPA=None, gNMDA=None, gGABA=None, vardt=False, return_cell=False, synapseID=None, tEnd=None, tStim=None)


   Simulate a single excitatory or inhibitory synapse.

   This is the core function to activate a single synapse and run the simulation.
   Used in the :py:class:`~simrun.synaptic_strength_fitting.PSPs` class to simulate each synapse.

   For excitatory synapses, :paramref:`gAMPA` and :paramref:`gNMDA` must be specified, and not :paramref:`gGABA`.
   For inhibitory synapses, only :paramref:`gGABA` may be specified.

   :param cell_nw_generator: A callable that returns a :py:class:`~single_cell_parser.cell.Cell` and :py:class:`~single_cell_parser.network.NetworkMapper` when called.
   :type cell_nw_generator: callable
   :param neuron_param: The :ref:`cell_parameters_format`.
   :type neuron_param: ~single_cell_parser.parameters.NTParameterSet
   :param network_param: The :ref:`network_parameters_format`.
   :type network_param: ~single_cell_parser.parameters.NTParameterSet
   :param celltype: The celltype to activate the synapse for. Used to fetch the correct network parameters.
   :type celltype: str
   :param preSynCellID: The presynaptic cell ID to activate the synapse for. Default: ``None``.
   :type preSynCellID: int
   :param gAMPA: The AMPA conductance value. Default: ``None``.
   :type gAMPA: float
   :param gNMDA: The NMDA conductance value. Default: ``None``.
   :type gNMDA: float
   :param gGABA: The GABA conductance value. Default: ``None``.
   :type gGABA: float
   :param vardt: Whether to use the variable step size solver. Default: ``False``.
   :type vardt: bool
   :param return_cell: Whether to return the :py:class:`~single_cell_parser.cell.Cell` object. Default: ``False``.
   :type return_cell: bool
   :param synapseID: The synapse ID to activate.
                     If ``None``, all synapses assigned to the presynaptic cell get activated synchronously during the simulation.
                     Default: ``None``.
   :type synapseID: int
   :param tEnd: The end time of the simulation. Default: ``None``.
   :type tEnd: float
   :param tStim: The time of the synaptic activation. Default: ``None``.
   :type tStim: float

   :returns: A tuple of the time vector and the voltage trace at the soma.
   :rtype: tuple
