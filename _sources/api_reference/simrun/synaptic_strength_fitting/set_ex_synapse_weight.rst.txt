

set_ex_synapse_weight
=====================


.. Signature -------------------------------

.. py:function:: simrun.synaptic_strength_fitting.set_ex_synapse_weight(syn, weight)


   Set the synaptic strength of an excitatory :py:class:`single_cell_parser.synapse.Synapse`.

   :param syn: The excitatory synapse to set the synaptic strength for.
   :type syn: single_cell_parser.synapse.Synapse
   :param weight: The synaptic strength values for the AMPA and NMDA components.
   :type weight: list

   :returns: None. Updates the synaptic strength of the excitatory synapse.
