

plot_vt
=======


.. Signature -------------------------------

.. function:: simrun.synaptic_strength_fitting.PSPs.plot_vt(population, opacity=1, g=1.0, merge=True, merge_celltype_kwargs={}, fig=None)


   Plot the voltage traces of the PSPs.

   :param population: The celltype to plot the voltage traces for.
   :type population: str
   :param opacity: The opacity of the voltage traces. Default: ``1``.
   :type opacity: float
   :param g: The synaptic strength value to plot the voltage traces for.
   :type g: float
   :param merge: Whether to merge the EPSPs of some cell types.
   :type merge: bool
   :param merge_celltype_kwargs: Additional keyword arguments to pass to :py:meth:`~simrun.synaptic_strength_fitting.merge_celltypes`.
   :type merge_celltype_kwargs: dict
   :param fig: A matplotlib figure to plot the voltage traces on.
   :type fig: plt.Figure

   :returns: None. Plots the voltage traces.
