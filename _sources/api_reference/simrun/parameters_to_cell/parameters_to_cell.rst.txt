

parameters_to_cell
==================


.. Signature -------------------------------

.. py:function:: simrun.parameters_to_cell.parameters_to_cell(neuronParam, networkParam, synfile=None, dirPrefix='', tStop=345.0, scale_apical=None, range_vars=None, allPoints=False, cell=None, evokedNW=None)


   Rebuild and simulate a network-embedded cell.

   Rebuild the cell from a :ref:`cell_parameters_format` file.
   If specified, the synapses in the :ref:`syn_file_format` file are reconnected and simulated according to the
   parameters defined in the :ref:`network_parameters_format` file. If no :ref:`syn_file_format` file is provided,
   a new network embedding is created based on the :ref:`network_parameters_format` file.

   :param neuronParam: Path to :ref:`cell_parameters_format` file.
   :type neuronParam: str
   :param networkParam: Path to :ref:`network_parameters_format` file.
   :type networkParam: str
   :param synfile: Path to the realized synapses in :ref:`syn_file_format` format.
   :type synfile: str
   :param dirPrefix: Prefix for the directory where the results are stored.
   :type dirPrefix: str
   :param tStop: Time in ms at which the simulation should stop.
   :type tStop: float
   :param scale_apical: Function to scale the apical dendrite.
   :type scale_apical: callable, DEPRECATED
   :param range_vars: Range variables to record.
   :type range_vars: str or list
   :param allPoints: Record all points in the cell.
   :type allPoints: bool
   :param cell: A cell object to use for the simulation.
   :type cell: Cell
   :param evokedNW: A network object to use for the simulation.
   :type evokedNW: NetworkMapper

   .. deprecated:: 0.1
       The `scale_apical` argument is deprecated.
       Use the `cell_modify_funs` key in the :ref:`cell_parameters_format` file instead.

   :returns: A tuple containing the :py:class:`~single_cell_parser.cell.Cell` and the evoked network (:py:class:`~single_cell_parser.network.Networkmapper`).
   :rtype: tuple
