

_assert_value
=============


.. Signature -------------------------------

.. function:: simrun.robust_dask_delayed_execution._assert_value(db, k, value, behaviour='warning')


   Assert that the value in the database is as expected.

   :param db: The path to the database.
   :type db: str
   :param k: The key in the database value.
   :type k: tuple
   :param value: The expected value.
   :param behaviour: The behaviour if the value is not as expected. Can be ``'warning'`` or ``'error'``.
   :type behaviour: str

   :raises RuntimeError: If the value is not as expected and the ``behaviour`` is ``'error'``.
   :raises ValueError: If the ``behaviour`` is not ``'warning'`` or ``'error'``.
