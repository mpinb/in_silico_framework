

get_status
==========


.. Signature -------------------------------

.. function:: simrun.robust_dask_delayed_execution.RobustDaskDelayedExecution.get_status()


   Get the status on the computation of the delayed objects.

   :returns: A dictionary with the keys being the keys of the delayed objects and the values being the status of the computation.
             Possible values are ``'not_started'``, ``'started'``, ``'finished'``.
   :rtype: dict
