

reset_status
============


.. Signature -------------------------------

.. function:: simrun.robust_dask_delayed_execution.RobustDaskDelayedExecution.reset_status(only_started=True)


   Reset the status of the delayed objects to ``'not_started'``.

   :param only_started: If ``True`` only the status of the delayed objects that are currently running is reset.
