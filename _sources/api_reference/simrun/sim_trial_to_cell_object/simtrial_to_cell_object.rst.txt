

simtrial_to_cell_object
=======================


.. Signature -------------------------------

.. function:: simrun.sim_trial_to_cell_object.simtrial_to_cell_object(db, sim_trial_index, compute=True, allPoints=False, scale_apical=None, range_vars=None, silent=True, neuron_param_modify_functions=[], network_param_modify_functions=[], synapse_activation_modify_functions=[], additional_network_params=[], tStop=345)


   Recreate and resimulate a single simulation trial from parameter files and return the cell object.

   This method also provides functionality to adapt the parameters of the cell, network, and synapse activation data
   before resimulating the trial. The network and neuron parameter modify functions should take the
   respective parameter dictionaries as input and return the modified dictionaries.
   Synapse activation modify functions should take the synapse activation data as input and return the modified data.

   :param db: A simrun-initialized database object.
   :type db: data_base.dataBase
   :param sim_trial_index: Index of the simulation trial in the database.
   :type sim_trial_index: int
   :param range_vars: Range variables to record.
   :type range_vars: str | list
   :param scale_apical: Function to scale the apical dendrites.
   :type scale_apical: callable, DEPRECATED
   :param allPoints: If True, skip :math:`d-\lambda` segmentation and simulate at high resolution.
   :type allPoints: bool
   :param compute: If True, compute the simulation. Otherwise return the simulation-ready :class:`~single_cell_parser.cell.Cell` object.
   :type compute: bool
   :param tStop: Stop time of the simulation.
   :type tStop: float
   :param neuron_param_modify_functions: List of functions to modify the neuron parameters.
   :type neuron_param_modify_functions: list
   :param network_param_modify_functions: List of functions to modify the network parameters.
   :type network_param_modify_functions: list
   :param synapse_activation_modify_functions: List of functions to modify the synapse activation data.
   :type synapse_activation_modify_functions: list
   :param silent: If True, suppress all output.
   :type silent: bool

   .. deprecated:: 0.1.0
       The `scale_apical` argument is deprecated and will be removed in a future version.
       Use the `cell_modify_functions` key in the :ref:`cell_parameters_format` file instead.

   .. seealso::

      :func:`simrun.sim_trial_to_cell_object.trial_to_cell_object`
      to recreate a single simulation trial from parameter files instead of a database.

   .. seealso::

      :mod:`data_base.db_initializers.init_simrun_general` to initialize a database object
      from raw `simrun` output, i.e. a "simrun-initialized" database object.

   :returns: The simulation-ready or simulated cell object.
   :rtype: :class:`~single_cell_parser.cell.Cell`
