




Solver_COBYLA._optimize
=======================


.. py:method:: simrun.modular_reduced_model_inference.solver.Solver_COBYLA._optimize(_objective_function, maxiter=5000, x0=None)

   :staticmethod:


   Static optimization method.

   This method is the core optimizer. It minimizes :paramref:`_objective_function` using
   :py:meth:`scipy.optimize.minimize` with ``method='COBYLA'``.

   :param _objective_function: A strategy-specific objective function.
