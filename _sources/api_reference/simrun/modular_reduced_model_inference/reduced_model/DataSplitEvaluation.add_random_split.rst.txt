

add_random_split
================


.. Signature -------------------------------

.. function:: simrun.modular_reduced_model_inference.reduced_model.DataSplitEvaluation.add_random_split(name, percentage_train=0.7, l=None)


   Set the train-test split randomly.

   :param name: Name of the split
   :type name: str
   :param percentage_train: Percentage of trials to use for training
   :type percentage_train: float
   :param l: List of indices to use for the split. If None, use all trials.
   :type l: list

   :raises AssertionError: If the split name already exists.
