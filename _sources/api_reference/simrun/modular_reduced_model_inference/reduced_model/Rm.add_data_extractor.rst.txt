




Rm.add_data_extractor
=====================


.. py:method:: simrun.modular_reduced_model_inference.reduced_model.Rm.add_data_extractor(name, data_extractor, setup=True)


   Add a data extractor to the reduced model.

   Data extractors are used to preprocess the data so that the strategies can use them.

   :param name: Name of the data extractor
   :type name: str
   :param data_extractor: Data extractor object
   :type data_extractor: ~simrun.modular_reduced_model_inference.data_extractor._DataExtractor
   :param setup: If True, run the setup method of the data extractor
   :type setup: bool

   .. seealso:: :py:mod:`~simrun.modular_reduced_model_inference.data_extractor` for available data extractors.
