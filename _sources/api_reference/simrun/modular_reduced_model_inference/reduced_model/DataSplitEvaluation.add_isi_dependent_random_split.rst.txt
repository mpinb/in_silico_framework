

add_isi_dependent_random_split
==============================


.. Signature -------------------------------

.. function:: simrun.modular_reduced_model_inference.reduced_model.DataSplitEvaluation.add_isi_dependent_random_split(name, min_isi=10, percentage_train=0.7)


   Split data based on the inter-spike interval.

   This method filters out trials with an inter-spike interval below a certain threshold.
   Only then the data is split into a train-test split.

   :param name: Name of the split
   :type name: str
   :param min_isi: Minimum inter-spike interval
   :type min_isi: float
   :param percentage_train: Percentage of trials to use for training
   :type percentage_train: float

   :raises AssertionError: If the split name already exists.
