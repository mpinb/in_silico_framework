

get_default_arguments
=====================


.. Signature -------------------------------

.. py:function:: simrun.utils.get_default_arguments(func)


   Gets the keyword arguments with their default value from any function.

   :param func: The function to get the default arguments from.
   :type func: callable

   :returns: Dictionary where the function names are keys, and their default values are values
   :rtype: dict
