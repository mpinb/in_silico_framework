

tar_folder
==========


.. Signature -------------------------------

.. py:function:: simrun.utils.tar_folder(source_dir, delete_folder=True)


   Compress a folder to ``.tar`` format.

   :param source_dir: The path to the folder to compress.
   :type source_dir: str
   :param delete_folder: If ``True``, the original folder will be deleted after compression.
   :type delete_folder: bool

   :returns: Compresses the folder in place.
   :rtype: None

   :raises RuntimeError: If the compression command fails
