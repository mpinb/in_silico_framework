

select_cells_that_spike_in_interval
===================================


.. Signature -------------------------------

.. py:function:: simrun.utils.select_cells_that_spike_in_interval(sa, tmin, tmax, set_index=['synapse_ID', 'synapse_type'])


   Select cells whose synapses were active in a given time interval.

   :param sa: The :ref:`syn_activation_format` DataFrame.
   :type sa: pd.DataFrame
   :param tmin: The start time of the interval.
   :type tmin: float
   :param tmax: The end time of the interval.
   :type tmax: float
   :param set_index: The index of the DataFrame. Default is ``['synapse_ID', 'synapse_type']``.
   :type set_index: list

   :returns: A list of tuples containing the synapse ID and the synapse type of the cells that spike in the interval.
   :rtype: list
