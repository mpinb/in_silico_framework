

get_fraction_of_landmarkAscii
=============================


.. Signature -------------------------------

.. function:: simrun.utils.get_fraction_of_landmarkAscii(frac, path)


   Sample landmarks (i.e. 3D points) from a landmarkAscii file.

   :param frac: Fraction of landmarks to sample.
   :type frac: float
   :param path: The path to the landmarkAscii file.
   :type path: str

   :returns: A pandas DataFrame containing the sampled landmarks and the cell type.
   :rtype: pd.DataFrame

   .. seealso:: :py:meth:`~simrun.utils.get_fraction_of_landmarkAscii_dir` to sample landmarks from all landmarkAscii files in a directory.
