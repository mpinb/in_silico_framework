

chunkIt
=======


.. Signature -------------------------------

.. py:function:: simrun.utils.chunkIt(seq, num)


   Split a sequence in multiple lists which have approximately equal size.

   :param seq: The sequence to split.
   :type seq: array
   :param num: The number of chunks.
   :type num: int

   :returns: A list of lists containing the chunks.
   :rtype: list

   .. seealso:: https://stackoverflow.com/questions/2130016/splitting-a-list-of-arbitrary-size-into-only-roughly-n-equal-parts
