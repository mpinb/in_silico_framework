




DataBaseRegister.search_dbs
===========================


.. py:method:: data_base.data_base_register.DataBaseRegister.search_dbs(directory=None)


   Look for :py:class:`DataBase` in all subfolders of the registry's directory and add them to the registry.

   :param directory: The directory to search in. Defaults to None, in which case the directory of the registry is searched.
   :type directory: str, optional
