

assimilate_remote_register
==========================


.. Signature -------------------------------

.. py:function:: data_base.data_base_register.assimilate_remote_register(remote_path, local_path=None)


   Assimilate a remote register.

   This method adds all databases from a remote register to the local register of the user.

   :param remote_path: The path to the remote register.
   :type remote_path: str
   :param local_path: The path to the local register. Defaults to None, in which case the default local register is used:
                      ``.data_base_register.db`` in the same directory as this file.
   :type local_path: str, optional
