

resolve_neup_reldb_paths
========================


.. Signature -------------------------------

.. function:: data_base.dbopen.resolve_neup_reldb_paths(neup, db_basedir)


   Convert all relative database paths in a :ref:`cell_parameters_format` file to absolute paths.

   :param neup: Dictionary containing the neuron model parameters.
   :type neup: dict
   :param db_basedir: Path to the database directory.
   :type db_basedir: str

   :returns: The modified neuron parameter set, with absolute paths.
   :rtype: :class:`~single_cell_parser.parameters.NTParameterSet`
