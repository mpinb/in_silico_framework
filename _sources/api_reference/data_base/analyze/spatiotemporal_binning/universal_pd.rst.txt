

universal_pd
============


.. Signature -------------------------------

.. py:function:: data_base.analyze.spatiotemporal_binning.universal_pd(df, distance_column, spatial_distance_bins=50, min_time=0, max_time=300, time_distance_bins=1)


   Bin a pandas DataFrame by both distance and time.

   This is a speed-optimized binning code for 2d-binning of a :py:class:`pandas.DataFrame`.

   :param df: DataFrame to bin. Must contain a column with the name :paramref:`distance_column` that contains the distance values.
   :type df: pandas.DataFrame
   :param distance_column: Column name of the distance values.
   :type distance_column: str
   :param spatial_distance_bins: Size of the distance bins. Default is :math:`50\mu m`.
   :type spatial_distance_bins: int
   :param min_time: Minimum time value. Default is :math:`0 ms`.
   :type min_time: int
   :param max_time: Maximum time value. Default is :math:`300 ms`.
   :type max_time: int
   :param time_distance_bins: Size of the time bins. Default is :math:`1 ms`.
   :type time_distance_bins: int

   :returns:     A 2D array of the binned values.
   :rtype: :py:class:`~numpy.array`
