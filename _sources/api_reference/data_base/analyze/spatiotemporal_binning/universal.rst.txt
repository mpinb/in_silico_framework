

universal
=========


.. Signature -------------------------------

.. function:: data_base.analyze.spatiotemporal_binning.universal(df, distance_column, spatial_distance_bins=50, min_time=0, max_time=300, time_distance_bins=1)


   Bin a pandas or dask DataFrame by both distance and time.

   Infers the type of the input DataFrame and calls the appropriate binning function.

   :param df: DataFrame to bin. Must contain a column with the name :param:`distance_column` that contains the distance values.
   :type df: ~dask.dataframe.DataFrame
   :param distance_column: Column name of the distance values.
   :type distance_column: str
   :param spatial_distance_bins: Size of the spatial bins. Default is :math:`50\mu m`.
   :type spatial_distance_bins: int
   :param min_time: Minimum time value. Default is :math:`0 ms`.
   :type min_time: int
   :param max_time: Maximum time value. Default is :math:`300ms`.
   :type max_time: int
   :param time_distance_bins: Size of the time bins. Default is :math:`1ms`.
   :type time_distance_bins: int

   :returns:     A 2D array of the binned values.
   :rtype: :class:`~numpy.array`

   .. seealso:: :func:`~data_base.analyze.spatial_binning.universal_pd`
