

temporal_binning_dask
=====================


.. Signature -------------------------------

.. py:function:: data_base.analyze.temporal_binning.temporal_binning_dask(ddf, bin_size=1, min_time=None, max_time=None, normalize=True, client=None)


   Bin timevalues in a dask DataFrame.

   Given a dataframe containing time values in columns whose name can be converted to an integer, this function bins the values.
   It assumes that all columns whose names are integer-convertible contain time values.
   This is true for :ref:`spike_times_format` and :ref:`syn_activation_format` dataframes.

   :param ddf: DataFrame with containing time values in columns whose name are integer-convertible.
   :type ddf: dask.dataframe.DataFrame
   :param bin_size: Size of the bins. If not specified, :paramref:`bin_borders` have to be specified.
   :type bin_size: float, optional
   :param min_time: Minimum time to consider. If not specified, the minimum value in the DataFrame is used.
   :type min_time: float, optional
   :param max_time: Maximum time to consider. If not specified, the maximum value in the DataFrame is used.
   :type max_time: float, optional
   :param normalize: If True, normalize the output to the total number of elements in the DataFrame.
   :type normalize: bool, optional
   :param client: Dask client to use for parallel computation.
   :type client: dask.distributed.Client

   :returns: Tuple containing the bin borders and the binned data.
   :rtype: tuple
