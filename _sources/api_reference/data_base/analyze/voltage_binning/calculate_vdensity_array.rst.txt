

calculate_vdensity_array
========================


.. Signature -------------------------------

.. function:: data_base.analyze.voltage_binning.calculate_vdensity_array(v, bin_size=0.05, ymin=-100, ymax=50, **kwargs)


   Calculate the voltage density array.

   A voltage density is the time-binned voltage across trials.
   This method infers the type of dataframe passed and calls the appropriate method.

   :param v: A voltage traces dataframe. Column indices float and reflect timepoints
   :type v: ~dask.dataframe.DataFrame
   :param bin_size: the size of the bins
   :type bin_size: float
   :param ymin: the minimum voltage value
   :type ymin: float
   :param ymax: the maximum voltage value
   :type ymax: float
