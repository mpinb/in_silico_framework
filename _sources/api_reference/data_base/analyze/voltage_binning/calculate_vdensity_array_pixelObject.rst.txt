

calculate_vdensity_array_pixelObject
====================================


.. Signature -------------------------------

.. function:: data_base.analyze.voltage_binning.calculate_vdensity_array_pixelObject(v, bin_size=0.05, ymin=-100, ymax=50, xmin=None, xmax=None, **kwargs)


   Calculate the voltage density array as a PixelObject.

   This method is identical to :func:`~data_base.analyze.voltage_binning.calculate_vdensity_array`,
   but returns a :class:`~visualize._figure_array_converter.PixelObject` instead.

   :param v: A voltage traces dataframe. Column indices float and reflect timepoints
   :type v: ~dask.dataframe.DataFrame
   :param bin_size: the size of the bins
   :type bin_size: float
   :param xmin: the minimum time value
   :type xmin: float
   :param xmax: the maximum time value
   :type xmax: float
   :param ymin: the minimum voltage value
   :type ymin: float
   :param ymax: the maximum voltage value
   :type ymax: float

   :returns: a PixelObject with the voltage density array
   :rtype: :class:`~visualize._figure_array_converter.PixelObject`
