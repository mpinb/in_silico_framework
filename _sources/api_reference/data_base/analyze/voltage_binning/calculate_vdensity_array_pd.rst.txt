

calculate_vdensity_array_pd
===========================


.. Signature -------------------------------

.. function:: data_base.analyze.voltage_binning.calculate_vdensity_array_pd(v, bin_size=0.05, ymin=-100, ymax=50, xmin=None, xmax=None)


   Bin a :ref:`voltage_traces_df_format` in timebins across trials.

   :param v: A voltage traces dataframe. Column indices float and reflect timepoints.
   :type v: ~pandas.DataFrame
   :param bin_size: The size of the bins.
   :type bin_size: float
   :param ymin: The minimum voltage value.
   :type ymin: float
   :param ymax: The maximum voltage value.
   :type ymax: float

   .. warning::

      If dask dataframe is passed, it will be monolithically load into memory.
      For large-scale simulations, this is likely not what you want.

   .. seealso:: :func:`~data_base.analyze.voltage_binning.calculate_vdensity_array_dask` for the dask version.
