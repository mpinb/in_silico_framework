

get
===


.. Signature -------------------------------

.. function:: data_base.isf_data_base.ISFDataBase.get(key, lock=None, **kwargs)


   Get data from the database.

   This is the main method to get data from a DataBase.
   This method allows to pass additional arguments to the Loader.
   Modules in :mod:`~data_base.isf_data_base.IO.LoaderDumper` make use of this feature
   if they require additional arguments in their ``load()`` method.

   This method is thread safe, if you provide a lock.

   :param key: The key to get from the database.
   :type key: str
   :param lock: If you use file locking, provide the lock that grants access. Defaults to None.
   :type lock: Lock, optional
   :param kwargs: Additional arguments to pass to the Loader.

   :returns: The object saved under ``db[key]``
   :rtype: object
