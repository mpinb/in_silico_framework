

_write_metadata
===============


.. Signature -------------------------------

.. function:: data_base.isf_data_base.ISFDataBase._write_metadata(dumper, dir_to_data)


   Writes the metadata of this database.

   .. warning:: Do not call this method directly. It is internal API. Invoking this method directly may be destructive.

   :param dumper: The dumper module that was used to save the data.
   :type dumper: module
   :param dir_to_data: The path to the data directory.
   :type dir_to_data: pathlib.Path
