




ISFDataBase.ls
==============


.. py:method:: data_base.isf_data_base.ISFDataBase.ls(depth=0, max_depth=2, max_lines=20, all_files=False, max_lines_per_key=3, color=True)


   Prints out the content of the database in a tree structure.

   In addition to simply printing it out, this method allows to specify how the tree should look.

   :param max_depth: How deep you want the filestructure to be. Defaults to 2.
   :type max_depth: int, optional
   :param max_lines: How long you want your total filelist to be. Defaults to 20.
   :type max_lines: int, optional
   :param max_lines_per_key: How many lines to print per key. Useful to limit visual output of subdatabases. Defaults to 3.
   :type max_lines_per_key: int, optional
   :param all_files: Whether to print all files (including e.g. ``Loader.json``), or only keys. Defaults to False.
   :type all_files: bool, optional

   :returns: None
