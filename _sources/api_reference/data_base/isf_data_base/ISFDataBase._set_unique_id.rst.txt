

_set_unique_id
==============


.. Signature -------------------------------

.. function:: data_base.isf_data_base.ISFDataBase._set_unique_id()


   Sets a unique ID for the DataBase as class attribute.

   Does not save this ID as metadata (this is taken care of by :func:`_initialize`)

   :raises ValueError: If the unique ID is already set.
