




ISFDataBase._convert_key_to_path
================================


.. py:method:: data_base.isf_data_base.ISFDataBase._convert_key_to_path(key)


   Infer the file path from a database key.

   :param key: The key to convert to a file path.
   :type key: str|tuple|pathlib.Path

   :returns: The file path corresponding to the key.
   :rtype: pathlib.Path

   Example::

       >>> key = ('my', 'nested', 'key')
       >>> db._convert_key_to_path(key)
       PosixPath('/path/to/database/db/my/db/nested/db/key')
