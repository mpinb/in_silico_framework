

create_sub_db
=============


.. Signature -------------------------------

.. function:: data_base.isf_data_base.ISFDataBase.create_sub_db(key, register='as_parent', **kwargs)


   Creates a database within a database.

   Example::
       >>> db.create_sub_db('my_sub_database')
       >>> db['my_sub_database']['some_key'] = ['some_value']

   :param key: The key of the sub_db
   :type key: str|tuple
   :param kwargs: overwrite (bool, optional): Whether to overwrite the sub_db if it already exists. Defaults to True.
                  Additional kwargs are passed to the dumper.
   :type kwargs: dict

   :returns: The newly created sub_db
   :rtype: ISFDataBase
