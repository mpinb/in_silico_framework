




ISFDataBase.create_sub_db
=========================


.. py:method:: data_base.isf_data_base.ISFDataBase.create_sub_db(key, register='as_parent', **kwargs)


   Creates a database within a database.

   Example::
       >>> db.create_sub_db('my_sub_database')
       >>> db['my_sub_database']['some_key'] = ['some_value']

   :param key: The key of the sub_db
   :type key: str|tuple
   :param register: ? TODO. Defaults to 'as_parent'.
   :type register: str, optional
   :param raise_: Whether to raise an error if the sub_db already exists. Defaults to True.
   :type raise_: bool, optional
   :param \*\*kwargs: overwrite (bool, optional): Whether to overwrite the sub_db if it already exists. Defaults to True.
                      Additional kwargs are passed to the dumper.
   :type \*\*kwargs: dict

   :returns: The newly created sub_db
   :rtype: ISFDataBase
