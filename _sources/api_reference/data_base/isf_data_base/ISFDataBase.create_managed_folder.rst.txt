

create_managed_folder
=====================


.. Signature -------------------------------

.. function:: data_base.isf_data_base.ISFDataBase.create_managed_folder(key, raise_=True)


   Create a folder in the db directory.

   You can delete the folder using del db[key]

   :param key: The key of the folder to create.
   :type key: str|tuple|pathlib.Path
   :param raise\_: Whether to raise an error if the folder already exists. Defaults to True.
   :type raise\_: bool, optional

   :returns: The created folder.
   :rtype: :class:`~data_base.isf_data_base.IO.LoaderDumper.just_create_folder.ManagedFolder`
