

keys
====


.. Signature -------------------------------

.. function:: data_base.isf_data_base.ISFDataBase.keys(recurse=False)


   Get the keys of the database.

   If recurse is set to True, all keys of subdatabases will be returned as well.

   :param recurse: Whether to return all keys, including subdatabase keys. Defaults to False.
   :type recurse: bool, optional

   :returns: The keys of the database as tuple or nested tuple of strings.
   :rtype: tuple
