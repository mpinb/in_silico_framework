

get_dumper_from_folder
======================


.. Signature -------------------------------

.. function:: data_base.isf_data_base.get_dumper_from_folder(folder, return_='module')


   Given a folder (i.e. database key), return the dumper that was used to save the data in that folder/key.

   :param folder: The folder in which the data is stored.
   :type folder: str
   :param return\_: Whether to return the dumper as a string or the actual module. Defaults to 'module'.
   :type return\_: str, optional

   :returns: The dumper that was used to save the data in that folder/key.
   :rtype: str | module
