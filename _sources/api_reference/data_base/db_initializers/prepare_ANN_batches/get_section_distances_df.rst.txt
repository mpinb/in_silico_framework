

get_section_distances_df
========================


.. Signature -------------------------------

.. function:: data_base.db_initializers.prepare_ANN_batches.get_section_distances_df(neuron_param_file, silent=True)


   Bin the morphology of a neuron from a :ref:`cell_parameters_format` file.

   This method reads the neuron parameter file and bins the morphology of the neuron into spatial bins.
   The amount of bins is inferred by :func:`~data_base.db_initializers.prepare_ANN_batches.get_binsize`.

   :param neuron_param_file: The path to the neuron parameter file.
   :type neuron_param_file: str
   :param silent: If True, suppresses output. Defaults to True.
   :type silent: bool, optional

   :returns: A dataframe containing the amount of bins, the bin size, and the min and max distance to the soma for each section.
   :rtype: pd.DataFrame

   Example::

       >>> section_distances_df = get_section_distances_df(neuron_param_file)
