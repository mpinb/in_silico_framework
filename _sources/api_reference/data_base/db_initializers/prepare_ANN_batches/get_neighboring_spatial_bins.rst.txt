

get_neighboring_spatial_bins
============================


.. Signature -------------------------------

.. function:: data_base.db_initializers.prepare_ANN_batches.get_neighboring_spatial_bins(cell, bin_id, section_distances_df)


   Get all the neighboring bins from a :param:`bin_id`.

   :param cell: cell object
   :type cell: cell
   :param bin_id: Bin id of format: ``"section_id/bin_id"``
   :type bin_id: _type_
   :param section_distances_df: DataFrame representing each section's spatial bins and binsizes.
   :type section_distances_df: pd.DataFrame

   :returns: list of all ids of bins that neighbor the given bin
   :rtype: list
