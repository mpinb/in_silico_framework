

get_synapse_activation_array_weighted
=====================================


.. Signature -------------------------------

.. py:function:: data_base.db_initializers.prepare_ANN_batches.get_synapse_activation_array_weighted(sa_, selected_stis=None, spatial_bin_names=None, min_time=0, max_time=600, bin_size=1, use_weights=False)


   Create a 4D array of synapse activation times.

   Create a 4D array of synaptic activation, where the axes are:

   - :paramref:`selected_stis`
   - EXC/INH
   - spatial bins
   - time bins

   The array is of shape ``(len(selected_stis), 2, len(spatial_bin_names), (max_time - min_time)//bin_size)``.

   :param sa_: Augmented synapse activation dataframe
   :type sa_: pd.DataFrame
   :param selected_stis: List of selected spike times. Defaults to None.
   :type selected_stis: list, optional
   :param spatial_bin_names: List of spatial bin names. Defaults to None.
   :type spatial_bin_names: list, optional
   :param min_time: Min time in ms. Defaults to 0.
   :type min_time: int, optional
   :param max_time: Max time in ms. Defaults to 600.
   :type max_time: int, optional
   :param use_weights: If True, weigh the synapse activation times with the corresponding synapse weights. Defaults to False.
   :type use_weights: bool, optional

   :returns: A 4D array of synapse activation times.
   :rtype: array
