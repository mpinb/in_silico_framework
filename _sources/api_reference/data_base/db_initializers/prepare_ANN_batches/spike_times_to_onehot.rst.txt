

spike_times_to_onehot
=====================


.. Signature -------------------------------

.. function:: data_base.db_initializers.prepare_ANN_batches.spike_times_to_onehot(spike_times, min_time=0, max_time=505, time_step=1)


   One-hot encode spike times to a binned time vector.

   The time vector is created from :param:`min_time`, :param:`max_time` and :param:`time_step`
   and is of length ``(max_time - min_time)//time_step``.

   If a spike occured in a certain time interval, the corresponding entry in the one-hot vector is set to ``True``.

   :param spike_times: Array of spike times
   :type spike_times: array
   :param min_time: Min time in ms. Defaults to 0.
   :type min_time: int, optional
   :param max_time: Max time in ms. Defaults to 505.
   :type max_time: int, optional
   :param time_step: Timestep in ms. Defaults to 1.
   :type time_step: int, optional

   :returns: A list of booleans, where each element represents a time step and is True if a spike occured in this interval.
   :rtype: list
