

temporal_binning_augmented_sa

   Bin synapse activation times into temporal bins.

   :param sa_augmented: Augmented synapse activation dataframe
   :type sa_augmented: pd.DataFrame
   :param min_time: Min time in ms
   :type min_time: int
   :param max_time: Max time in ms
   :type max_time: int
   :param bin_size: Size of the time bins
   :type bin_size: int
   :param use_weights: If True, weigh the synapse activation times with the corresponding synapse weights.
                       Defaults to False.
   :type use_weights: bool, optional

   :returns: A tuple containing the bin borders and the histogram of synapse activation times.
