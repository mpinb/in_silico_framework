

get_bin
=======


.. Signature -------------------------------

.. py:function:: data_base.db_initializers.prepare_ANN_batches.get_bin(value, bin_min, bin_max, n_bins, tolerance=0.1)


   Find the bin index of a given value.

   :param value: The value to find the bin for.
   :type value: float
   :param bin_min: Start of the first bin.
   :type bin_min: float
   :param bin_max: End of the last bin.
   :type bin_max: float
   :param n_bins: The number of bins.
   :type n_bins: int
   :param tolerance: The tolerance for the outer ibn edges (for rounding errors). Defaults to 0.1.
   :type tolerance: float, optional

   :returns: The bin the value belongs to.
   :rtype: int
