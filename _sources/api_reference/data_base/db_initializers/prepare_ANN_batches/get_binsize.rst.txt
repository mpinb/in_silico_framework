

get_binsize
===========


.. Signature -------------------------------

.. py:function:: data_base.db_initializers.prepare_ANN_batches.get_binsize(length, binsize_goal=50)


   Calculate the bin size and number of bins closest to the desired bin size goal.

   :param length: The length of a dendritic branch to bin.
   :type length: float
   :param binsize_goal: The desired bin size. Defaults to 50.
   :type binsize_goal: float, optional

   :returns: A tuple containing the bin size (float) and the number of bins (int) that result in binning closest to the binsize goal.
   :rtype: tuple
