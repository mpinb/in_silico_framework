

get_max_per_ms_on_pandas_dataframe
==================================


.. Signature -------------------------------

.. function:: data_base.db_initializers.prepare_ANN_batches.get_max_per_ms_on_pandas_dataframe(vt_pandas)


   Subsample a voltage trace pandas dataframe to 1ms bins based on the maximum depolarization.

   :param vt_pandas: Voltage traces dataframe
   :type vt_pandas: pd.DataFrame

   :returns: A pandas Series of the maximum depolarization per ms.
   :rtype: pd.Series

   .. attention:: This method assumes a voltage trace time interval of 0.025 ms.
