

create_metadata
===============


.. Signature -------------------------------

.. function:: data_base.db_initializers.load_simrun_general.metadata_utils.create_metadata(db)


   Generate metadata out of a pd.Series containing the sim_trial_index.

   Maps the ``sim_trial_index`` to a pandas Series containing the path, trial number,
   and filename of the voltage traces file. After running this method, the database
   contains:

   - ``sim_trial_index`` A pandas series containing the sim_trial_index.
   - ``simresult_path`` Path to the simulation results folder.

   :param db: The target database that should contain the parsed simulation results.
   :type db: ~data_base.DataBase

   :returns: A pandas dataframe containing the metadata.
   :rtype: pd.DataFrame
