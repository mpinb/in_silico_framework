

add_dendritic_voltage_traces
============================


.. Signature -------------------------------

.. function:: data_base.db_initializers.load_simrun_general.add_dendritic_voltage_traces(db, rewrite_in_optimized_format=True, dendritic_spike_times=True, repartition=True, dendritic_spike_times_threshold=-30.0, scheduler=None, client=None)


   Add dendritic voltage traces to the database.

   Used in :func:`~data_base.db_initializers.load_simrun_general.init` to read, parse
   and write the membrane voltage of recorded sites to the database.

   :param db: The database to which the data should be added.
   :type db: ~data_base.DataBase
   :param rewrite_in_optimized_format: If True, the data is converted to a high performance format.
                                       Default is ``True``.
   :type rewrite_in_optimized_format: bool, optional
   :param dendritic_spike_times: If True, the dendritic spike times are added to the database.
                                 Default is ``True``.
   :type dendritic_spike_times: bool, optional
   :param repartition: If True, the dask dataframe is repartitioned to 5000 partitions (only if it contains over :math:`10000` entries).
                       Default is ``True``.
   :type repartition: bool, optional
   :param dendritic_spike_times_threshold: Threshold for the dendritic spike times in :math:`mV`. Default is :math:`-30 mV`.
                                           See also: :func:`~data_base.db_initializers.load_simrun_general.add_dendritic_spike_times`
   :type dendritic_spike_times_threshold: float, optional
   :param client: Distributed Client object for parallel computation.
   :type client: ~dask.distributed.client.Client
