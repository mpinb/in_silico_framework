

_estimate_average_vt_length
===========================


.. Signature -------------------------------

.. function:: data_base.db_initializers.load_simrun_general.data_parsing._estimate_average_vt_length(fnames, sample_size=1)


   Estimate the length of all voltage traces in :param:`fnames`

   Reads the headers of :param:`sample_size` random files in :param:`fnames` to fetch
   how many voltage traces they contain. Returns the average amount.

   :param fnames: List of voltage trace filenames.
   :type fnames: List[str]
   :param sample_size: Amount of voltage traces headers to read in order to infer their length.
                       Set to ``1`` if you expect all votlage trace filenames in :param:`fnames` to be of equal length.
   :type sample_size: int

   :returns: Estimated average length of all voltage trace files.
   :rtype: int
