

_generate_target_filenames
==========================


.. Signature -------------------------------

.. py:function:: data_base.db_initializers.load_simrun_general.param_file_parser._generate_target_filenames(db, db_target_dir, filelist, copy_method='remount', client=None)


   Generate target filenames within a database directory for an array of source files.

   The target filenames can be configured in :py:mod:`~data_base.db_initializers.load_simrun_general.config`
   by changing :py:attr:`PARAM_FILE_COPY_METHOD` and the target directory names of each file type.

   :param db: The database to which the data should be added.
   :type db: ~data_base.DataBase
   :param dir_name: The directory relative to the database where the files of one type should be copied.
                    These directories will be a :py:class:`data_base.isf_data_base.ManagedFolder`
   :type dir_name: str
   :param filelist: The original file names.
   :type filelist: List[str]
   :param client: A parallellization client. Only needed if ``"PARAMFILE_COPY_METHOD"`` is configured to ``"hash_rename"``
   :type client: distributed.client.Client

   :returns: The target filename in the database.
   :rtype: str
