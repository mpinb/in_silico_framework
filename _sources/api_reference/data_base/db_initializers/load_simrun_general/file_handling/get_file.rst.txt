

get_file
========


.. Signature -------------------------------

.. py:function:: data_base.db_initializers.load_simrun_general.file_handling.get_file(self, suffix)


   Get the filename of the unique file in the current directory with the specified suffix.

   This method does not recurse into subdirectories.

   :param self: Path to the directory.
   :type self: str
   :param suffix: Suffix of the files to be found.
   :type suffix: str

   :returns: Path to the file with the specified suffix.
   :rtype: str

   :raises ValueError: If no file with the specified suffix is found.
   :raises ValueError: If multiple files with the specified suffix are found.
