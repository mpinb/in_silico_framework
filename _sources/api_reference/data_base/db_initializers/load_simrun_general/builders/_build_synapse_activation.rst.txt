

_build_synapse_activation
=========================


.. Signature -------------------------------

.. py:function:: data_base.db_initializers.load_simrun_general.builders._build_synapse_activation(db, repartition=False, n_chunks=5000)


   Parse the :ref:`syn_activation_format` and :ref:`spike_times_format` data.

   The synapse and presynaptic spike times data is added to the database under the keys
   ``synapse_activation`` and ``cell_activation`` respectively.

   :param db: The database to which the data should be added.
   :type db: ~data_base.DataBase
   :param repartition: If True, the dask dataframe is repartitioned to 5000 partitions (only if it contains over :math:`10000` entries).
   :type repartition: bool
   :param n_chunks: Number of chunks to split the data into. Default is 5000.
   :type n_chunks: int

   :returns: None
