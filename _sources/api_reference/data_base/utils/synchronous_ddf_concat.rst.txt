

synchronous_ddf_concat
======================


.. Signature -------------------------------

.. function:: data_base.utils.synchronous_ddf_concat(ddf_path, meta, N, n, scheduler=None)


   Concatenate a pickles dask dataframe to a pandas dataframe.

   :param ddf_path: path to the dask dataframe
   :type ddf_path: str
   :param meta: the metadata for the dask dataframe.
   :type meta: pd.DataFrame
   :param N: number of chunks
   :type N: int
   :param n: the chunk to be concatenated
   :type n: int
   :param scheduler: the scheduler to be used
   :type scheduler: str

   :returns: the concatenated dataframe
   :rtype: pd.DataFrame
