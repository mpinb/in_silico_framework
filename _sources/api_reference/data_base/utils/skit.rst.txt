

skit
====


.. Signature -------------------------------

.. function:: data_base.utils.skit(*funcs, **kwargs)


   Splits kwargs up to supply different functions with the right subset.

   :param funcs: functions to be supplied with the right subset of kwargs
   :type funcs: List[callable]
   :param kwargs: keyword arguments to be split up
