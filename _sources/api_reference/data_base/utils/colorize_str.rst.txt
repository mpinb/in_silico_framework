

colorize_str
============


.. Signature -------------------------------

.. function:: data_base.utils.colorize_str(key, bcolor)


   Colorize a string with a terminal color.

   Simply concatenates the string with escape sequences that colroize the text in a terminal.

   :param key: the string
   :type key: str
   :param bcolor: the color
   :type bcolor: str

   :returns: the colorized string
   :rtype: str

   .. seealso:: :class:`data_base.utils.bcolors` For color escape sequences.
