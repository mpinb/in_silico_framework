

chunkIt
=======


.. Signature -------------------------------

.. function:: data_base.utils.chunkIt(seq, num)


   Splits :param:`seq` in :param:`num` lists, with approximately equal size.

   :param seq: array to be split
   :type seq: array
   :param num: number of chunks
   :type num: int

   .. seealso:: https://stackoverflow.com/questions/2130016/splitting-a-list-of-arbitrary-size-into-only-roughly-n-equal-parts
