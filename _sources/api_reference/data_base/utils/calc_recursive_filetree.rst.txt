

calc_recursive_filetree
=======================


.. Signature -------------------------------

.. py:function:: data_base.utils.calc_recursive_filetree(db, root_dir_path, max_lines=30, depth=0, max_depth=2, max_lines_per_key=3, lines=None, indent=None, all_files=False, colorize=True)


   Fetches the contents of an db and formats them as a string representing a tree structure

   :param db: The database to be visualized
   :type db: data_base.data_base.DataNase
   :param root_dir_path: The path to the root directory
   :type root_dir_path: str
   :param max_depth: Maximum depth to recurse into the directory tree
   :type max_depth: int
   :param max_lines: Maximum number of lines to print. Default is 30.
   :type max_lines: int
   :param max_lines_per_key: Maximum number of lines per key. Default is 3.
   :type max_lines_per_key: int
   :param lines: List of strings to append to during recursion. Default is ``None``.
   :type lines: list
   :param all_files: If True, all files are shown (including e.g. /db subfolders). If False, only files that are keys in the database are shown. Default is ``False``.
   :type all_files: bool
   :param colorize: If True, colorizes the keys. Default is ``True``.
   :type colorize: bool

   :returns: The formatted tree structure as a list of strings.
   :rtype: list
