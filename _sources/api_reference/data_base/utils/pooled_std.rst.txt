

pooled_std
==========


.. Signature -------------------------------

.. function:: data_base.utils.pooled_std(m, s, n)


   Calculates the pooled standard deviation out of samples.

   :param m: means
   :type m: array
   :param s: unbiased standard deviation (normalized by N-1)
   :type s: array
   :param n: number of samples per group
   :type n: array

   :returns: pooled mean and pooled standard deviation
   :rtype: tuple
