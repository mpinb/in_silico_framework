

get_file
========


.. Signature -------------------------------

.. function:: data_base.IO.LoaderDumper.just_create_folder.ManagedFolder.get_file(suffix)


   Get the files that end with the specified suffix.

   :param suffix: Suffix of the file
   :type suffix: str

   :raises ValueError: If there are no files with the specified suffix or more than one file with the specified suffix

   :returns: The filepath of the file with :param:`suffix` (only if there is exactly one file with this suffix)
   :rtype: str
