==========================


.. Signature -------------------------------

.. py:function:: data_base.IO.LoaderDumper.resolve_loader_dumper_path(loader_path)


   Resolve a loader path to an absolute path.

   This is used to import the loader module from the relative path.

   :param loader_path: The relative path to the loader module.
   :type loader_path: str

   :returns: The absolute path to the loader module.
   :rtype: str
