

save_object_meta
================


.. Signature -------------------------------

.. function:: data_base.IO.LoaderDumper.meta.save_object_meta(obj, savedir)


   Save an object's meta in the file format configured in py:mod:`config`.

   :param obj: The dataframe to save the meta of.
   :type obj: dask.DataFrame | parquet.DataFrame
   :param savedir: The directory to save the meta file in.
   :type savedir: str

   :returns: Writes result to disk.
   :rtype: None
