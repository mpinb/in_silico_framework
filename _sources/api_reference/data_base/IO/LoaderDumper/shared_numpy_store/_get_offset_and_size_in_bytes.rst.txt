

_get_offset_and_size_in_bytes
=============================


.. Signature -------------------------------

.. function:: data_base.IO.LoaderDumper.shared_numpy_store._get_offset_and_size_in_bytes(start_row, end_row, shape, dtype)


   Get the offset and size in bytes for a given ``start_row`` and ``end_row``.

   Rows here refer to the first dimension of a multi-dimensional array.

   :param start_row: The starting row of the array.
   :type start_row: int
   :param end_row: The ending row of the array.
   :type end_row: int
   :param shape: The shape of the array. ``shape[0]`` is the number of rows.
   :type shape: tuple
   :param dtype: The data type of the array. Used to infer the size in bytes.
   :type dtype: str

   :returns: A tuple containing the ``start_row``, ``end_row``, ``bytes_offset``, ``bytes_size``, and ``final_shape``.
   :rtype: tuple
