

get_dumper_string_by_savedir
============================


.. Signature -------------------------------

.. py:function:: data_base.IO.LoaderDumper.get_dumper_string_by_savedir(savedir)


   Get the dumper string from a filepath.

   This function reads the ``Loader.json`` file in the savedir and returns the dumper in string format.

   :param savedir: The path to the saved data. Must contain a ``Loader.json`` file.
   :type savedir: str

   :returns: The dumper string.
   :rtype: str
