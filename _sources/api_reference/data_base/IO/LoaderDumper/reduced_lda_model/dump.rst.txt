

dump
====


.. Signature -------------------------------

.. py:function:: data_base.IO.LoaderDumper.reduced_lda_model.dump(obj, savedir)


   Save the reduced model in the specified directory as a DataBase.

   The database will contain the following keys:

   - ``st``: Spike times with a precision of :math:`.01`.
   - ``lda_value_dicts_<index>``: Dictionaries of LDA values with a precision of :math:`.01`.
   - ``Rm``: The reduced model.

   :param obj: Reduced model to be saved.
   :type obj: ~simrun.reduced_model.get_kernel.ReducedLdaModel
   :param savedir: Directory where the reduced model should be stored.
   :type savedir: str
