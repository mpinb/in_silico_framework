

load
====


.. Signature -------------------------------

.. function:: data_base.IO.LoaderDumper.load(savedir, load_data=True, loader_kwargs={})


   Standard interface to load data.

   Loads the data's respective ``Loader`` in the same directory as the data.
   Uses this ``Loader`` to load the data

   :param savedir: Path to the data
   :type savedir: str
   :param load_data: Whether to load the data (default), or just the ``Loader`` object. Useful for debugging purposes.
   :type load_data: bool
   :param loader_kwargs: Additional keyword arguments for the loader. Note that the ``Loader.json`` file should in principle contain all necessary information.
   :type loader_kwargs: dict

   :returns: The loaded object: either the data, or the ``Loader`` object.
   :rtype: object
