

get_db_by_unique_id
===================


.. Signature -------------------------------

.. function:: data_base.get_db_by_unique_id(unique_id)


   Get a DataBase by its unique ID, as registered in the data base register.

   Data base registers should be located at data_base/.data_base_register.db

   :param unique_id: The data base's unique identifier
   :type unique_id: str

   :returns: The database associated with the :param:`unique_id`.
   :rtype: :class:`data_base.DataBase`
