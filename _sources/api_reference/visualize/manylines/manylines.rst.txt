

manylines
=========


.. Signature -------------------------------

.. py:function:: visualize.manylines.manylines(df, ax=None, axis=None, colormap=None, groupby_attribute=None, figsize=(15, 3), returnPixelObject=False, scheduler=None)


   Parallelizes the plot of many lines

   :param df: the dataframe containing voltage traces,
   :type df: pd.DataFrame
   :param ax: an ax instance.
   :type ax: matplotlib.pyplot.Axes
   :param axis: the ax limits, e.g. [1, 10, 1, 10]
   :type axis: list
   :param colormap: a colormap, mapping values for :paramref:groupby_attribute to colors.
   :type colormap: dict
   :param groupby_attribute: column name to group by.
   :type groupby_attribute: str
   :param figsize: the size of the Figure
   :type figsize: tupe(int)
   :param returnPixelObject: Whether or not to return as a PixelObject
   :type returnPixelObject: bool
   :param scheduler: a distributed scheduler.
   :type scheduler: distributed.client.Client | str, optional

   :returns: Figure object containing all lines defined in :paramref:`df`
   :rtype: :py:class:`~matplotlib.figure.Figure`
