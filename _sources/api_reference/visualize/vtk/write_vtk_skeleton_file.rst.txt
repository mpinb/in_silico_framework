

write_vtk_skeleton_file
=======================


.. Signature -------------------------------

.. function:: visualize.vtk.write_vtk_skeleton_file(lookup_table, out_name, out_dir, point_scalar_data=None, n_decimals=2)


   Write out a .vtk file for a neuron morphology.

   This method is used by :func:`~visualize.cell_morphology_visualizer.CellMorphologyVisualizer.write_vtk_frames`.

   :param lookup_table: Lookup table for the neuron morphology.
                        Can be accessed from :class:`visualize.cell_morphology_visualizer.CellMorphologyVisualizer`.
   :type lookup_table: pd.DataFrame
   :param out_name: Name of the output file.
   :type out_name: str
   :param out_dir: Directory to save the file to.
   :type out_dir: str
   :param point_scalar_data: Dictionary containing scalar data for each point. Defaults to None.
   :type point_scalar_data: dict, optional

   :returns: None. Writes out a .vtk file to the specified directory.
