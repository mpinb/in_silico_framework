

convert_amira_lattice_to_vtk
============================


.. Signature -------------------------------

.. py:function:: visualize.vtk.convert_amira_lattice_to_vtk(surf_file, outname='lattice', outdir='.')


   Convert an AMIRA lattice file to vtk structured points.

   :param surf_file: Path to the AMIRA lattice file.
   :type surf_file: str
   :param outname: Name of the output file. Defaults to "lattice".
   :type outname: str, optional
   :param outdir: Directory to save the file to. Defaults to ".".
   :type outdir: str, optional

   :returns: None. Writes out a .vtk file to the specified directory.
