

write_vtk_pointcloud_file
=========================


.. Signature -------------------------------

.. py:function:: visualize.vtk.write_vtk_pointcloud_file(out_name=None, out_dir='.', points=None, scalar_data=None, scalar_data_names=None)


   Write out 3D point data as a VTK point cloud.

   :param out_name: Name of the output file.
   :type out_name: str
   :param out_dir: Directory to save the file to.
   :type out_dir: str
   :param points: List of 3D points.
   :type points: list
   :param scalar_data: List of scalar data arrays. Each array should have the same length as the amount of points.
   :type scalar_data: list
   :param scalar_data_names: List of names for the scalar data arrays.
   :type scalar_data_names: list

   :returns: None. Writes out a .vtk file to the specified directory.
