

convert_amira_surf_to_vtk
=========================


.. Signature -------------------------------

.. function:: visualize.vtk.convert_amira_surf_to_vtk(surf_file, outname='surface', outdir='.')


   Given the path to an amira .surf file, this method converts it to a .vtk surface file.

   :param surf_file: path to amira .surf file
   :type surf_file: str
   :param outname: Name of the output vtk surface file. Defaults to 'surface'.
   :type outname: str, optional
   :param outdir: Directory to save the file to. Defaults to '.'.
   :type outdir: str, optional

   :returns: None. Writes out a .vtk file to the specified directory.
