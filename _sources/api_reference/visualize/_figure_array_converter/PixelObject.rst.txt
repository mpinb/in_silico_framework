.. class:: visualize._figure_array_converter.PixelObject(extent, ax=None, array=None)
   
   Dataclass to hold pixel information from either a :class:`matplotlib.pyplot.Axes` or a numpy array.

   :param extent: The extent of the plot.
   :type extent: list
   :param ax: The axis to convert to a pixel array. Default is ``None``.
   :type ax: matplotlib.pyplot.Axes
   :param array: The pixel array to store. Default is ``None``.
   :type array: numpy.ndarray

   :Attributes:

      .. attribute:: extent

         The extent of the plot.

         :type: list

      .. attribute:: array

         The pixel array of the plot.

         :type: numpy.ndarray

      :raises ValueError: If neither an ax nor an array is specified.
      :raises ValueError: If both an ax and an array are specified
