




DendrogramStatistics.plot
=========================


.. py:method:: visualize.dendrogram.DendrogramStatistics.plot(figsize=None, colormap_synapses=None)


   Plot the dendrogram statistics.

   :param figsize: The figure size. Default is ``None``.
   :type figsize: tuple
   :param colormap_synapses: A dictionary mapping color to synapse types. The keys must match the synapse types in the dendrogram.
                             Missing keys will be omitted from the visualization alltogether. Default: `None` (plot all synapses in black).
   :type colormap_synapses: dict

   :returns: The matplotlib figure object.
   :rtype: :py:class:`matplotlib.figure.Figure`
