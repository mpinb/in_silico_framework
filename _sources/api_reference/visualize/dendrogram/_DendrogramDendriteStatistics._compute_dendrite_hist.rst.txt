

_compute_dendrite_hist
======================


.. Signature -------------------------------

.. function:: visualize.dendrogram._DendrogramDendriteStatistics._compute_dendrite_hist(dist_end=None, binsize=50)


   Compute the dendrite density histogram.

   :param dist_end: The maximum soma distance. Default is ``None`` and the maximum soma distance is calculated.
   :type dist_end: float
   :param binsize: The size of the bins in :math:`\mu m`. Default is :math:`50 \mu m`.
   :type binsize: float

   :returns: Nothing. Updates :param:`bins` and :param:`dendrite_density`.
   :rtype: None
