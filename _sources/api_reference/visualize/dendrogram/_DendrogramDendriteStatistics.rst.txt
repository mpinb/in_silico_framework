.. class:: visualize.dendrogram._DendrogramDendriteStatistics(dendrogram_db, colormap_synapses=None)
   
   Compute dendrite statistics from a dendrogram.

   Dendrite statistics includes the total amount of dendritic length in a certain bin of soma distance.
   This is useful for calculating synapse statistics as well.

   :param dendrogram_db: A list of :class:`_DendrogramSection` objects.
   :type dendrogram_db: list
   :param colormap_synapses: A dictionary mapping color to synapse types. The keys must match the synapse types in the dendrogram.
                             Missing keys will be omitted from the visualization alltogether. Default: `None` (plot all synapses in black).
   :type colormap_synapses: dict

   :Attributes:

      .. attribute:: dendrogram_db

         A list of :class:`_DendrogramSection` objects.

         :type: list

      .. attribute:: colormap_synapses

         A dictionary mapping color to synapse types. The keys must match the synapse types in the dendrogram.
         Missing keys will be omitted from the visualization alltogether. Default: `None` (plot all synapses in black).

         :type: dict

      .. attribute:: bins

         The bins of the dendrite density histogram.

         :type: np.array

      .. attribute:: dendrite_density

         The dendrite density histogram, i.e. the amount of dendritic length within a range of soma distance.

         :type: np.array
