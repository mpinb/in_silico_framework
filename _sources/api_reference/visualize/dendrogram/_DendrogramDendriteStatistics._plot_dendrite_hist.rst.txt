

_plot_dendrite_hist

.. Signature -------------------------------

.. function:: visualize.dendrogram._DendrogramDendriteStatistics._plot_dendrite_hist(ax, xlim, binsize=50)


   Base method for plotting a histogram of dendrite length on an :class:`matplotlib.axes.Axes` object.

   :param ax: The matplotlib axes object.
   :type ax: matplotlib.axes.Axes
   :param xlim: The x-axis limits.
   :type xlim: tuple
   :param binsize: The size of the bins in :math:`\mu m`. Default is :math:`50 \mu m`.
   :type binsize: float

   :returns: The matplotlib axes object.
   :rtype: :class:`matplotlib.axes.Axes`
