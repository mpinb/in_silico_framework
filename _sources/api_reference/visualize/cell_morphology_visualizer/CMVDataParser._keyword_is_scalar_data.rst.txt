




CMVDataParser._keyword_is_scalar_data
=====================================


.. py:method:: visualize.cell_morphology_visualizer.CMVDataParser._keyword_is_scalar_data(keyword)


   Check if a keyword is a scalar data type.

   :param keyword: keyword to check. Example: "grey", "vm", "voltage", "dendrites", "dendritic group"
   :type keyword: str

   :returns: True if the keyword refers to scalar data, False if it is a solid color like "grey".
   :rtype: bool
