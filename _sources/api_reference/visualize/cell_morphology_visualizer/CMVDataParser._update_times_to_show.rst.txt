

_update_times_to_show
=====================


.. Signature -------------------------------

.. function:: visualize.cell_morphology_visualizer.CMVDataParser._update_times_to_show(t_start=None, t_stop=None, t_step=None)


   Checks if the specified time range equals the previously defined one. If not, updates the time range.
   If all arguments are None, does nothing. Useful for defining default time range

   :param t_start: start time
   :type t_start: float
   :param t_stop: end time
   :type t_stop: float
   :param t_step: time interval
   :type t_step: float

   :returns: None. Updates :param:`times_to_show`.
