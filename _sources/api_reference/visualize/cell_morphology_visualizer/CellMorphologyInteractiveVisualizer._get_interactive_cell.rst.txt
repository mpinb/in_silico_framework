

_get_interactive_cell
=====================


.. Signature -------------------------------

.. function:: visualize.cell_morphology_visualizer.CellMorphologyInteractiveVisualizer._get_interactive_cell(color=None, time_point=None, diameter=None)


   Setup plotly for rendering in notebooks.
   Shows an interactive 3D render of the Cell with NO data overlayed.

   :param color: If you want some other color overlayed on the cell morphology.
                 Options: "voltage", "vm", "synapses", "synapse", or a color string, or a nested list of colors for each section
   :type color: str | list
   :param time_point: time_point at which to plot some scalar data. Ignored when color does not refer to scalar data.
   :type time_point: float | int
   :param diameter: If the actual diameter is poorly visible, set this value to a fixed diameter.

   :returns: an interactive figure. Usually added to a ipywidgets.VBox object
   :rtype: plotly.graph_objs._figure.Figure
