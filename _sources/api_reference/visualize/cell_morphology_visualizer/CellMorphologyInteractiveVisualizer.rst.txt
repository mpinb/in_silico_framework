.. py:class:: visualize.cell_morphology_visualizer.CellMorphologyInteractiveVisualizer(cell, align_trunk=True, dash_ip=None, show=True, renderer='notebook_connected', t_start=None, t_stop=None, t_step=None)
   
   Plot an interactive 3D render of a cell morphology using Plotly and Dash.

   Initializes the CellMorphologyInteractiveVisualizer object.

   :param cell: Cell object
   :type cell: ~single_cell_parser.cell.Cell
   :param align_trunk: Whether or not to align the cell trunk with the z-axis.
   :type align_trunk: bool
   :param dash_ip: IP address to run dash server on.
   :type dash_ip: str
   :param show: set to False for testing
   :type show: bool
   :param renderer: Type of backend renderer to use for rendering the javascript/HTML VBox. Defaults to "notebook_connected"
   :type renderer: str
   :param t_start: start time point of our time series visualization
   :type t_start: float
   :param t_stop: last time point of our time series visualization
   :type t_stop: float
   :param t_step: time between the different time points of our visualization
   :type t_step: float

   :Attributes:

      .. attribute:: dash_ip

         IP address to run dash server on.

         :type: str

      .. attribute:: show

         Whether to show the plot. Set to False for testing purposes. Default: True

         :type: bool

      .. attribute:: background_color

         Background color of the plot. Defaults to "#f0f0f0"

         :type: str

      .. attribute:: renderer

         Type of backend renderer to use for rendering the javascript/HTML VBox.
         Defaults to "notebook_connected". Available renderers are:
         
         - 'plotly_mimetype'
         - 'jupyterlab'
         - 'nteract'
         - 'vscode'
         - 'notebook'
         - 'notebook_connected'
         - 'kaggle'
         - 'azure'
         - 'colab'
         - 'cocalc'
         - 'databricks'
         - 'json'
         - 'png'
         - 'jpeg'
         - 'jpg'
         - 'svg'
         - 'pdf'
         - 'browser'
         - 'firefox'
         - 'chrome'
         - 'chromium'
         - 'iframe'
         - 'iframe_connected'
         - 'sphinx_gallery'
         - 'sphinx_gallery_png'

         :type: str

   :Methods:

      * - :py:obj:`_get_interactive_dash_app <visualize.cell_morphology_visualizer.CellMorphologyInteractiveVisualizer._get_interactive_dash_app>`\ (color, t\_start, t\_stop, t\_step)
