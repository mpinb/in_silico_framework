

set_cmap
========


.. Signature -------------------------------

.. function:: visualize.cell_morphology_visualizer.CMVDataParser.set_cmap(cmap=None, vmin=None, vmax=None)


   Update the colormap, vmin, and vmax of the visualization.

   :param cmap: colormap to use. Default is "jet". For available colormaps, see https://matplotlib.org/stable/gallery/color/colormap_reference.html
   :type cmap: str
   :param vmin: minimum value of the colormap. Default is ``None``.
   :type vmin: float
   :param vmax: maximum value of the colormap. Default is ``None``.
   :type vmax: float

   :returns: Nothing.
   :rtype: None
