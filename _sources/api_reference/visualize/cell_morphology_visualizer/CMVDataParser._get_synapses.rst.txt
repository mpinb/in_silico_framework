

_get_synapses
=============


.. Signature -------------------------------

.. function:: visualize.cell_morphology_visualizer.CMVDataParser._get_synapses(active_only=False)


   Retrieves the synapse locations per synapse group.

   :param active_only: Only fetch those synapses that actually activate at some point.
   :type active_only: bool

   :returns:     dictionary where each key is the type of the input population and the value is a list of synapse coordinates for that type of population.
                 If :param:`rotation_with_zaxis` is not None, the synapse coordinates are rotated to align with the z-axis.
   :rtype: dict
