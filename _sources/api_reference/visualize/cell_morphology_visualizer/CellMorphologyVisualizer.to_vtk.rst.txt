

to_vtk
======


.. Signature -------------------------------

.. function:: visualize.cell_morphology_visualizer.CellMorphologyVisualizer.to_vtk(out_dir='.', fn='')


   Write out the cell morphology to a VTK file.

   .. attention:: This function does not support time series. It will write out the cell morphology without any scalar data.

   :param out_dir: path of the directory where the VTK file will be stored.
   :type out_dir: str
   :param fn: name of the VTK file. If empty, the file will be named after the cell's :ref:`morphology_file_format` filename.
   :type fn: str

   :returns: writes the .VTK file.
   :rtype: None
