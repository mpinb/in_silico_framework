

write_video
===========


.. Signature -------------------------------

.. function:: visualize.cell_morphology_visualizer.CellMorphologyVisualizer.write_video(images_path, out_name, overwrite_frames=False, color='grey', show_synapses=False, show_legend=False, client=None, t_start=None, t_stop=None, t_step=None, highlight_section=None, highlight_x=None, quality=5, codec='mpeg4', tpf=20)


   Write the individual frames of a neuron during a simulation and merge them into a video.

   Creates a set of images of a neuron color-coded with voltage together with synapse activations.
   The parameters :param:`t_start`, :param:`t_stop` and :param:`t_step` update the :param:`times_to_show` attribute.

   :param images_path: dir where the images for the gif will be generated
   :type images_path: str
   :param out_name: path location of the resulting gif.
   :type out_name: str
   :param overwrite_frames: whether to overwrite previously existing frames in the images_path directory.
   :type overwrite_frames: bool
   :param color: color of the cell morphology. Can be a fixed color, or a keyword referring to scalar data of the simulation, such as membrane voltage or ion channel dynamics.
   :type color: str
   :param show_synapses: whether to show the synapse activation locations onto the morphology.
   :type show_synapses: bool
   :param show_legend: whether to show the color legend in the plot.
   :type show_legend: bool
   :param client: dask client for parallelization
   :type client: distributed.client.Client
   :param t_start: start time point of our time series visualization
   :type t_start: float
   :param t_stop: last time point of our time series visualization
   :type t_stop: float
   :param t_step: time between the different time points of our visualization
   :type t_step: float
   :param highlight_section: section number of the section that should be highlighted with an arrow.
   :type highlight_section: int
   :param highlight_x: x coordinate of the section that should be highlighted with an arrow.
   :type highlight_x: float
   :param quality: quality of the output video. 1 is the highest quality and 31 is the lowest quality. This is ignored if :param:`codec` is not MPEG* (mpeg4, mpeg2video, mpeg1video, mjpeg, libxvid, msmpeg4).
   :type quality: int
   :param codec: codec to use for the video. Default is mpeg4.
   :type codec: str
   :param tpf: duration of each frame in ms
   :type tpf: float
