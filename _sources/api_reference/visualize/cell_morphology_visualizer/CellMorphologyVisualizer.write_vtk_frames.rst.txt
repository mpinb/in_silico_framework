

write_vtk_frames
================


.. Signature -------------------------------

.. function:: visualize.cell_morphology_visualizer.CellMorphologyVisualizer.write_vtk_frames(out_name='frame', out_dir='.', t_start=None, t_stop=None, t_step=None, color=None, n_decimals=2, client=None)


   Write the cell morphology to a series of VTK files.

   :param out_name: name of the file (not path, the file will be generated in out_dir)
   :type out_name: str
   :param out_dir: path where the images for the gif will be generated
   :type out_dir: str
   :param t_start: start time point of our time series visualization
   :type t_start: float
   :param t_stop: last time point of our time series visualization
   :type t_stop: float
   :param t_step: time between the different time points of our visualization
   :type t_step: float
   :param color: color of the cell morphology. Can be a fixed color, or a keyword referring to scalar data of the simulation, such as membrane voltage or ion channel dynamics.
   :type color: str
   :param n_decimals: number of decimals to round the data to. Default is 2.
   :type n_decimals: int
   :param client: dask client for parallelization
   :type client: distributed.client.Client
