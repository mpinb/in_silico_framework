

_calc_scalar_data
=================


.. Signature -------------------------------

.. function:: visualize.cell_morphology_visualizer.CMVDataParser._calc_scalar_data(keyword)


   Updates the scalar data according to some keyword (ion dynamics or membrane voltage).

   :param keyword: keyword to determine the scalar data. Can be a color, ion dynamics, or membrane voltage.
   :type keyword: str

   :returns: None. Updates the scalar data.
