

plot
====


.. Signature -------------------------------

.. function:: visualize.cell_morphology_visualizer.CellMorphologyVisualizer.plot(color='grey', show_legend=True, show_synapses=False, time_point=None, save='', highlight_section=None, highlight_x=None)


   Plot the cell morphology in 3D.

   Cam be used to create a static plot of the cell morphology, which may be color-coded with voltage, ion dynamics, or synapse activations.

   :param color: If you want some other color overlayed on the cell morphology.
                 Options: "voltage", "vm", "synapses", "synapse", or a color string, or a nested list of colors for each section
   :type color: str | [[float]]
   :param show_legend: whether the voltage legend should appear in the plot
   :type show_legend: bool
   :param show_synapses: whether the synapse activations should be shown
   :type show_synapses: bool
   :param time_point: time point from which we want to gather the voltage/synapses. Defaults to 0
   :type time_point: int|float
   :param save: path where the plot will be saved. If it's empty it will not be saved (Default)
   :type save: bool
   :param highlight_section: section number of the section that should be highlighted
   :type highlight_section: int
   :param highlight_x: x coordinate of the section that should be highlighted
   :type highlight_x: float

   :returns: matplotlib figure containing the plot.
   :rtype: fig
