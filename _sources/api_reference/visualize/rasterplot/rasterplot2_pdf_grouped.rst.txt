

rasterplot2_pdf_grouped
=======================


.. Signature -------------------------------

.. py:function:: visualize.rasterplot.rasterplot2_pdf_grouped(pdf, grouplabel, ax=None, xlim=None, x_offset=0, color='k')


   Plot a rasterplot per group of :ref:`spike_times_format`.

   Similar to :py:meth:`~rasterplot2`, this method plots a rasterplot from a spike times dataframe,
   but groups them with horizontal lines, based on the grouplabel.
   Assumes the spike times dataframe has a column :paramref:`grouplabel`

   :param pdf: A DataFrame containing the spike times.
               Must contain a column with label :paramref:`grouplabel`.
   :type pdf: pandas.DataFrame
   :param grouplabel: The column name in the DataFrame to group by.
   :type grouplabel: str
   :param ax: An optional Matplotlib Axes object to plot on. If not provided, a new figure and axes are created.
   :type ax: matplotlib.axes.Axes, optional
   :param xlim: The x-axis limits for the plot. Default is ``None``.
   :type xlim: tuple, optional
   :param x_offset: An offset to apply to the x-values (event times). Default is 0.
   :type x_offset: float, optional
   :param color: The color to use for the plot. Default is 'k'.
   :type color: str, optional
