

write_gif_from_images
=====================


.. Signature -------------------------------

.. function:: visualize.utils.write_gif_from_images(images, out_path, interval=40, images_format='.png', auto_sort_paths=True)


   Creates a gif from a set of images, and saves it to :param:`out_path`.

   :param images: list of images, a directory with images or a list of directories with images
   :type images: list | str
   :param out_path: dir where the video will be generated + name of the gif
   :type out_path: str
   :param interval: time interval between frames (ms)
   :type interval: int | float
   :param images_format: .png, .pdf, .jpg ...
   :type images_format: str
   :param auto_sort_paths: paths to images sorted
   :type auto_sort_paths: bool

   :returns: None. Writes the gif to the specified path.
