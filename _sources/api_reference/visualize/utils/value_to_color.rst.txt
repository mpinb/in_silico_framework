

value_to_color
==============


.. Signature -------------------------------

.. py:function:: visualize.utils.value_to_color(v, vmin=0, vmax=1)


   Map a value to a color.

   See: https://stackoverflow.com/questions/15140072/how-to-map-number-to-color-using-matplotlibs-colormap

   :param v: The value to map to a color.
   :type v: float
   :param vmin: The minimum value of the range. Default is 0.
   :type vmin: float
   :param vmax: The maximum value of the range. Default is 1.
   :type vmax: float

   :returns: The RGBA color tuple.
   :rtype: tuple
