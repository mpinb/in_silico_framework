.. py:class:: visualize.utils.Arrow3D(x, y, z, dx, dy, dz, *args, **kwargs)
   
   Draw a 3D annotation arrow on a matplotlib 3D plot

   See: https://gist.github.com/WetHat/1d6cd0f7309535311a539b42cccca89c

   :param x: x coordinate of the arrow starting point.
   :type x: float
   :param y: y coordinate of the arrow starting point.
   :type y: float
   :param z: z coordinate of the arrow starting point.
   :type z: float
   :param dx: x coordinate difference of the arrow direction.
   :type dx: float
   :param dy: y coordinate difference of the arrow direction.
   :type dy: float
   :param dz: z coordinate difference of the arrow direction.
   :type dz: float
   :param \*args: Additional positional arguments passed to FancyArrowPatch.
   :param \*\*kwargs: Additional keyword arguments passed to FancyArrowPatch.

   :Attributes:

      .. attribute:: _xyz

         the x, y, z coordinates of the arrow

         :type: tuple

      .. attribute:: _dxdydz

         the dx, dy, dz coordinate difference of the arrow, i.e. where it points to relative to its origin.

         :type: tuple

   :Methods:
