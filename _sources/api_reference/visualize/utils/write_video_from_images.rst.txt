

write_video_from_images
=======================


.. Signature -------------------------------

.. py:function:: visualize.utils.write_video_from_images(images, out_path, fps=24, images_format='.png', quality=5, codec='mpeg4', auto_sort_paths=True)


   Creates a video from a set of images.

   Images must be specified as a list of images, a directory with images or a list of directories with images.
   Uses glob pattern matching if a directory of images is specified (allows for using the "*" as a wildcard).

   .. note::

      Globbing is not enabled by default on Windows machines.
      If running this command on windows, please set the :paramref:`glob` argument to False and specify a non-glob type match pattern.

   :param images: list of images, a directory with images or a list of directories with images
   :type images: list | str
   :param out_path: dir where the video will be generated + name of the video
   :type out_path: str
   :param fps: frames per second
   :type fps: int
   :param images_format: .png, .pdf, .jpg ...
   :type images_format: str
   :param quality: quality of the video. Only used with the mpeg4 codec
   :type quality: int
   :param codec: codec to use. Default is mpeg4.
   :type codec: str
   :param auto_sort_paths: paths to images sorted
   :type auto_sort_paths: bool

   :returns: None. Writes the video to the specified path.
