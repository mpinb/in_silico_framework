




CurrentAnalysis.plot_areas
==========================


.. py:method:: visualize.current_visualizer.CurrentAnalysis.plot_areas(ax=None, normalized=False, plot_net=False, plot_voltage=False, t_stim=295, select_window_relative_to_stim=(0, 55))


   Plot the ion currents and the net current of a cell simulation.

   :param ax: The matplotlib axes object. Default is ``None``.
   :type ax: Axes
   :param normalized: Whether to plot the normalized currents. Default is ``False``.
   :type normalized: bool
   :param plot_net: Whether to plot the net current. Default is ``False``.
   :type plot_net: bool
   :param plot_voltage: Whether to plot the voltage trace. Default is ``False``.
   :type plot_voltage: bool
   :param t_stim: The time of the stimulus im :math:`ms`. Default is :math:`295 ms`.
   :type t_stim: int
   :param select_window_relative_to_stim: The time window to select relative to the stimulus time. Default is ``(0, 55)``.
   :type select_window_relative_to_stim: tuple

   :returns: None
