

_load_base64
============


.. Signature -------------------------------

.. py:function:: visualize.cell_to_ipython_animation._load_base64(filename, extension='png')


   Load a file and encode it in base64.

   This is used to load images and embed them in an html file, such as Jupyter notebooks.

   :param filename: path to file
   :type filename: str
   :param extension: the file extension. Default: 'png'
   :type extension: str

   :returns: base64 encoded string
   :rtype: str

   .. seealso:: https://github.com/jakevdp/JSAnimation/blob/master/JSAnimation/html_writer.py
