

parallelMovieMaker
==================


.. Signature -------------------------------

.. function:: visualize.cell_to_ipython_animation.parallelMovieMaker(basedir, lines, xlim=(0, 1500), ylim=(-80, 0))


   Creates figures in parallel and returns animation object.

   :param basedir: path to store images
   :type basedir: str
   :param lines: list of dictionaries of lines (generated by function generate_lines)
   :type lines: list
   :param xlim: limits of x axis
   :type xlim: tuple
   :param ylim: limits of y axis
   :type ylim: tuple

   :returns: list of paths to images
   :rtype: list
