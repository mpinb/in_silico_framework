

display_animation
=================


.. Signature -------------------------------

.. py:function:: visualize.cell_to_ipython_animation.display_animation(files, interval=10, style=False, animID=None, embedded=False)


   Creates an IPython animation out of files specified in a globstring or a list of paths.

   :param files: globstring or list of paths
   :type files: str | list
   :param interval: time interval between frames
   :type interval: int
   :param style: whether to use the style specified in the system default html_template.
   :type style: bool
   :param animID: unique integer to identify the animation in the javascript environment of IPython
   :param embedde: whether to embed the images as base64 in the html file.
   :type embedde: bool

   .. attention::

      The paths need to be relative to the location of the ipynb / html file, since
      the are resolved in the browser and not by python

   :returns: the animation object
   :rtype: IPython.display.HTML
