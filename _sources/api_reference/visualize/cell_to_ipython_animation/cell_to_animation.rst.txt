

cell_to_animation
=================


.. Signature -------------------------------

.. function:: visualize.cell_to_ipython_animation.cell_to_animation(cell, xlim=None, ylim=None, tstart=245, tend=310, tstep=1, range_vars='Vm', plot_synaptic_input=False, outdir='animation')


   Takes a cell object and creates a 2d animation plotting the range_vars vs soma distance over time.

   :param outdir: folder, where animation should be saved. The result will be .png files.
   :type outdir: str
   :param xlim: tuple like (0, 1600) that defines the limits of the x axis.
                If None, tries to get default values for range var from get_default_axis
                Default: None.
   :type xlim: tuple
   :param ylim: tuple like (-80 0) that defines the limits of the y axis
                If None, tries to get default values for range var from get_default_axis
                Default: None.
   :type ylim: tuple
   :param tstart: time when animation should be started
   :type tstart: float
   :param tend: time when animation should be stopped
   :type tend: float
   :param tstep: timestep between frames
   :type tstep: float
   :param range_vars: str or list of str: range vars to display, default: 'Vm'
   :type range_vars: str | list

   :returns: list of paths to images
   :rtype: list
