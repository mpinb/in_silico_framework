

plot_hoc
========


.. Signature -------------------------------

.. py:function:: visualize.plot_hoc(hoc_file, **kwargs)


   Plot a hoc file using matplotlib.

   Instatiate a :py:class:`CellMorphologyVisualizer` object to plot a morphology from a :ref:`hoc_file_format` file.

   :param hoc_file: The path to the :ref:`hoc_file_format` file
   :type hoc_file: str
   :param show: Whether to show the plot
   :type show: bool
   :param \*\*kwargs: additional arguments to pass to :py:meth:`CellMorphologyVisualizer.plot`

   :returns: The figure object
   :rtype: :py:class:`~matplotlib.figure.Figure`
