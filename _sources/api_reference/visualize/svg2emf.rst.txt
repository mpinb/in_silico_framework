

svg2emf
=======


.. Signature -------------------------------

.. py:function:: visualize.svg2emf(filename, path_to_inkscape='/usr/bin/inkscape')


   Converts svg to emf, which can be imported in Word using inkscape.

   :param filename: the filename of the svg file
   :type filename: str
   :param path_to_inkscape: the path to the inkscape binary
   :type path_to_inkscape: str

   :returns: None
