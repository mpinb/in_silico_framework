

hay_param_to_scp_neuron_param
=============================


.. Signature -------------------------------

.. function:: biophysics_fitting.hay.L5tt_parameter_setup.hay_param_to_scp_neuron_param(p)


   Convert a Hay parameter name to a SCP neuron parameter name.

   This function is a simple converter that converts the Hay naming convention to what ISF
   uses internally in :mod:`~single_cell_parser.cell.Cell`

   :param p: The Hay parameter name.
   :type p: str

   :returns: The SCP neuron parameter name.
   :rtype: str

   .. rubric:: Example
      :class: example

   >>> hay_param_name = "NaTa_t.axon.gNaTa_tbar"
   >>> hay_param_to_scp_neuron_param(hay_param_name)
   "NaTa_t.AIS.gNaTa_tbar"  # axon --> AIS

   .. seealso:: See :cite:t:`Hay_Hill_Schuermann_Markram_Segev_2011` for more information.
