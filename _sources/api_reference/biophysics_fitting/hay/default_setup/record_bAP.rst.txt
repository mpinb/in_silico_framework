

record_bAP
==========


.. Signature -------------------------------

.. function:: biophysics_fitting.hay.default_setup.record_bAP(cell, recSite1=None, recSite2=None)


   Extract the voltage traces from the soma and two apical dendritic locations.

   This is used to quantify the voltage trace of a backpropagating AP (bAP)
   stimulus in a pyramidal neuron. The two apical recording sites are used
   to calculate e.g. backpropagating attenuation.

   :param cell: The cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param recSite1: The distance (um) from the soma to the first recording site.
   :type recSite1: float
   :param recSite2: The distance (um) from the soma to the second recording site.
   :type recSite2: float

   .. seealso:: See :cite:t:`Hay_Hill_Schuermann_Markram_Segev_2011` for more information.
