

get_Evaluator
=============


.. Signature -------------------------------

.. py:function:: biophysics_fitting.hay.default_setup.get_Evaluator(step=False, vInit=False, bAP_kwargs={}, BAC_kwargs={}, StepOne_kwargs={}, StepTwo_kwargs={}, StepThree_kwargs={}, interpolate_voltage_trace=True)


   Get a :py:class:`~biophysics_fitting.evaluator.Evaluator` object for the Hay protocol.

   Sets up an evaluator object for the Hay protocol, including measuring functions for bAP, BAC and three step current stimuli.

   :param step: Whether to include step current measurements (not implemented yet).
   :type step: bool
   :param vInit: Whether to include vInit measurements. (not implemented yet)
   :type vInit: bool
   :param bAP_kwargs: Keyword arguments for the ``bAP`` measurement function.
   :type bAP_kwargs: dict
   :param BAC_kwargs: Keyword arguments for the ``BAC`` measurement function.
   :type BAC_kwargs: dict
   :param StepOne_kwargs: Keyword arguments for the ``StepOne`` measurement function.
   :type StepOne_kwargs: dict
   :param StepTwo_kwargs: Keyword arguments for the ``StepTwo`` measurement function.
   :type StepTwo_kwargs: dict
   :param StepThree_kwargs: Keyword arguments for the ``StepThree`` measurement function.
   :type StepThree_kwargs: dict
   :param interpolate_voltage_trace: Whether to interpolate the voltage trace to a fixed time interval.
   :type interpolate_voltage_trace: bool

   :returns: An evaluator object.
   :rtype: :py:class:`~biophysics_fitting.evaluator.Evaluator`

   :raises NotImplementedError: If :paramref:vInit is set to True.

   .. seealso:: See :cite:t:`Hay_Hill_Schuermann_Markram_Segev_2011` for more information.
