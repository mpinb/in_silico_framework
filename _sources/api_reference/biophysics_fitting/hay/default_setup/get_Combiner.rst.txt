

get_Combiner
============


.. Signature -------------------------------

.. function:: biophysics_fitting.hay.default_setup.get_Combiner(step=False, include_DI3=True)


   Get a set up :class:`~biophysics_fitting.combiner.Combiner` object for the Hay protocol.

   :param step: Whether to include step current measurements.
   :type step: bool
   :param include_DI3: Whether to include the doublet ISI for the Step3 protocol in the step current measurements.
                       Default: ``True``.
   :type include_DI3: bool

   :returns: A combiner object.
   :rtype: :class:`~biophysics_fitting.combiner.Combiner`

   .. seealso:: See :cite:t:`Hay_Hill_Schuermann_Markram_Segev_2011` for more information.
