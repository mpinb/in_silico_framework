

get_Simulator
=============


.. Signature -------------------------------

.. function:: biophysics_fitting.hay.default_setup.get_Simulator(fixed_params, step=False, vInit=False)


   Get a set up :class:`~biophysics_fitting.simulator.Simulator` object for the Hay protocol.

   Given cell-specific fixed parameters, set up a simulator object for the Hay protocol,
   including measuring functions for bAP and BAC stimuli (no step currents)

   :param fixed_params: A dictionary of fixed parameters for the cell.
   :type fixed_params: dict
   :param step: Whether to include step current measurements. These take quite long to simulate. Default: ``False``.
   :type step: bool
   :param vInit: Whether to include vInit measurements. (not implemented yet)
   :type vInit: bool

   :returns: A simulator object.
   :rtype: :class:`~biophysics_fitting.simulator.Simulator`

   .. seealso:: See :cite:t:`Hay_Hill_Schuermann_Markram_Segev_2011` for more information.
