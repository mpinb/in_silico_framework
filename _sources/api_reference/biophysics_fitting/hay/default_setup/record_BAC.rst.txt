

record_BAC
==========


.. Signature -------------------------------

.. py:function:: biophysics_fitting.hay.default_setup.record_BAC(cell, recSite=None)


   Extract the voltage traces from the soma and an apical dendritic location.

   This is used to quantify the voltage trace of a bAP-Activated Ca2+ (BAC) stimulus

   :param cell: The cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param recSite: The distance (um) from the soma to the apical recording site.
   :type recSite: float

   .. seealso:: See :cite:t:`Hay_Hill_Schuermann_Markram_Segev_2011` for more information.
