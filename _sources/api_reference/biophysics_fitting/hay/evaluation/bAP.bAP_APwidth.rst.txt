

bAP_APwidth
===========


.. Signature -------------------------------

.. function:: biophysics_fitting.hay.evaluation.bAP.bAP_APwidth(voltage_traces)


   Get the width of the first action potential in the somatic voltage trace.

   :param voltage_traces: dictionary with the voltage traces of the soma and dendrite.
   :type voltage_traces: dict

   :returns: Dictionary mapping ``".check_1AP"`` to whether there is at least one action potential in the somatic voltage trace,
             and ``".raw"`` to the width of the first action potential in the somatic voltage trace.
   :rtype: dict

   .. seealso:: :func:`~biophysics_fitting.ephys.APwidth`
