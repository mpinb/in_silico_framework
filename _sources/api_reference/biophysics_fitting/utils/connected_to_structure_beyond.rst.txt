

connected_to_structure_beyond
=============================


.. Signature -------------------------------

.. function:: biophysics_fitting.utils.connected_to_structure_beyond(cell, sec, beyond_dist, beyond_struct=['ApicalDendrite'], n_children_required=1)


   Checks if a :py:class:`~single_cell_parser.cell.Cell` section is connected to a structure
   at a soma distance larger than :paramref:`beyond_dist`.

   :param cell: The cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param sec: The section to check.
   :type sec: ~single_cell_parser.section.Section
   :param beyond_dist: The distance from the soma to check.
   :type beyond_dist: float
   :param beyond_struct: The labels of the structures to check.
   :type beyond_struct: list
   :param n_children_required: The minimum number of children required to have a connection.
   :type n_children_required: int

   This can be helpful to detect the main bifurcation of a L5PT, which is the bifurcation in which both children are connected to the tuft.
