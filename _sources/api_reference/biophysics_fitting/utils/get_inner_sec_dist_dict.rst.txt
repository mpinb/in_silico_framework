

get_inner_sec_dist_dict
=======================


.. Signature -------------------------------

.. function:: biophysics_fitting.utils.get_inner_sec_dist_dict(cell, beyond_dist=1000, beyond_struct=['ApicalDendrite'], n_children_required=1)


   Get sections that connect to specific structures beyond a minimum distance.

   Fetches all sections that are connected to compartments with labels in :paramref:`beyond_struct`, and
   that have a minimum soma distance of :paramref:`beyond_dist`.
   This is useful to get sections of the apical trunk of an L5PT, filtering out oblique dendrites.

   :param cell: The cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param beyond_dist: The minimum distance from the soma (um).
   :type beyond_dist: float
   :param beyond_struct: The labels of the structures to check.
   :type beyond_struct: list
   :param n_children_required: The minimum number of children required to have a connection.
   :type n_children_required: int

   :returns: A dictionary with the soma distance as key and the section as value.
   :rtype: dict

   .. seealso:: See also: :py:meth:`~get_inner_section_at_distance` that returns the closest section at a specific distance, rather than all sections beyond some distance.
