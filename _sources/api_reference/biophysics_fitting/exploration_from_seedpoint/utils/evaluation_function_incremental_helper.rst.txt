

evaluation_function_incremental_helper
======================================


.. Signature -------------------------------

.. function:: biophysics_fitting.exploration_from_seedpoint.utils.evaluation_function_incremental_helper(p, s=None, e=None, cutoffs=None, stim_order=None, verbose=True, additional_evaluation_functions=None, objectives_by_stimulus=None)


   Evaluate a model shows one stimulus at a time.

   This is useful for performace, as it allows to run the fastest simulations first,
   and provides an early stopping criterion if a model is not able to match these objectives.

   :param s: Simulator object
   :type s: ~biophysics_fitting.simulator.Simulator
   :param e: Evaluator object
   :type e: ~biophysics_fitting.evaluator.Evaluator
   :param stim_order: Order in which stimuli are simulated.
                      List consisting of strings and tuples of strings.
                      Use strings if only one stimulus is to be simulated.
                      Use tuples of strings to simulate several stimuli in one go.
   :type stim_order: [str] | [(str)]
   :param cutoffs: Keys (str) must appear in stim_order.
                   Values (float)indicate the maximum error allowed for these stimuli
   :type cutoffs: Dict[str,float]
   :param objectives_by_stimulus: Keys (str) must appear in stim_order.
                                  Values (list) are objective names returned by the evaluator object.
   :type objectives_by_stimulus: Dict[str,list]
   :param additional_evaluation_functions: additional functions to be applied onto the final voltage
                                           traces dictionary, which return a dictionary which is appended to the
                                           evaluations.
   :type additional_evaluation_functions: list

   :returns: True if all stimuli pass. False if at least one stimulus has an error above its cutoff.
