

robust_read_pickle
==================


.. Signature -------------------------------

.. py:function:: biophysics_fitting.exploration_from_seedpoint.RW_analysis.robust_read_pickle(path)


   Read a pickled dataframe. If it cannot be read, still return a dataframe, containing an error as content.
   Useful for when you don't want your code to error during some large-scale analysis.

   :param path: path to the pickled dataframe
   :type path: str

   :returns: the pickled DataFrame if reading was succesful, a pd.Series otherwise. Both contain the key 'init_error', specifying whether or not the read was succesful.
   :rtype: pd.DataFrame | pd.Series
