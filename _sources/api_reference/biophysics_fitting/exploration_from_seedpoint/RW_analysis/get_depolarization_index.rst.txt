

get_depolarization_index
========================


.. Signature -------------------------------

.. function:: biophysics_fitting.exploration_from_seedpoint.RW_analysis.get_depolarization_index(dataframe)


   Compute the relative difference in depolarization contribution of Ca_LVA and Ca_HVA during the BAC stimulus.

   This index is defined as:

   .. math::

       \frac{Ca_{LVA} - Ca_{HVA}}{Ca_{HVA} + Ca_{LVA}}

   :param dataframe: the dataframe containing the biophysical parameters
   :type dataframe: pd.DataFrame

   :returns: the depolarization index for each model in the dataframe
   :rtype: pd.Series

   .. note:: This method is specific to L5PT neurons, or any cell with Ca_LVA and Ca_HVA channels.
