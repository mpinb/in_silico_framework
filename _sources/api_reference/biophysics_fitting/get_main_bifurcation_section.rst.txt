

get_main_bifurcation_section
============================


.. Signature -------------------------------

.. function:: biophysics_fitting.get_main_bifurcation_section(cell)


   Find the main bifurcation of a cell.
   This is the unique inner section whose branching depth is 1.
   In some morphologies, this section is unique, and no other sections are inner sections with branching depth 1.
   This is True for e.g. pyramidal cells with an apical dendrite.

   :param cell: The Cell object for which to find the main bifurcation section.
   :type cell: ~single_cell_parser.cell.Cell

   :raises AssertionError: If there are multiple sections who are both inner, and have branching depth 1. This means that there is no "main" bifurcation in the morphology.

   :returns: The unique section that contains the main bifurcation.
   :rtype: :class:`~single_cell_parser.cell.PySection`
