

_append
=======


.. Signature -------------------------------

.. py:function:: biophysics_fitting.setup_stim._append(cell, name, item)


   Append an item to a :py:class:`~single_cell_parser.Cell.cell` object.

   This is used to add e.g. injection/recording pipettes to the cell.

   :param cell: The cell object.
   :type cell: object
   :param name: The name of the attribute to append to.
   :type name: str
   :param item: The item to append.
   :type item: object

   :returns: None. Adds :paramref:`item` to the :paramref:`cell` under the name :paramref:`name`.
