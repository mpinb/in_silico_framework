

setup_StepThree
===============


.. Signature -------------------------------

.. py:function:: biophysics_fitting.setup_stim.setup_StepThree(cell, delay=700)


   Setup a step current stimulus at the soma:

   - amplitude = 1.507 nA
   - delay = 700 ms
   - duration = 2000 ms

   :param cell: The cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param delay: The delay of the step current stimulus (ms).
   :type delay: float

   :returns: None. Adds a step current stimulus to the cell.
