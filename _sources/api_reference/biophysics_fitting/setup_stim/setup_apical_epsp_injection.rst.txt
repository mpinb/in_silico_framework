

setup_apical_epsp_injection
===========================


.. Signature -------------------------------

.. py:function:: biophysics_fitting.setup_stim.setup_apical_epsp_injection(cell, dist=None, amplitude=None, delay=None, rise=1.0, decay=5)


   Setup an EPSP injection at a given distance from the soma.

   This method assumes the :paramref:`cell` has a soma and an apical dendrite.
   It checks so by means of section label: it must contain a section
   labeled "ApicalDendrite". See :py:meth:`~biophysics_fitting.utils.get_inner_section_at_distance` for more information.

   :param cell: The cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param dist: The distance from the soma to the injection site (um).
   :type dist: float
   :param amplitude: The amplitude of the EPSP (nA).
   :type amplitude: float
   :param delay: The delay of the EPSP (ms).
   :type delay: float
   :param rise: The rise time constant of the EPSP (ms).
   :type rise: float
   :param decay: The decay time constant of the EPSP (ms).
   :type decay: float

   :returns: None. Adds an EPSP injection pipette to the cell under the name 'epsp'.
