

setup_bAP
=========


.. Signature -------------------------------

.. py:function:: biophysics_fitting.setup_stim.setup_bAP(cell, delay=295)


   Setup a bAP (backpropagating action potential) stimulus for the cell.

   Soma:

   - shape = step
   - amplitude = 1.9 nA
   - delay = 295 ms
   - duration = 5 ms

   :param cell: The cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param delay: The delay of the bAP stimulus (ms).
   :type delay: float

   :returns: None. Adds a bAP stimulus to the cell.
