

set_param
=========


.. Signature -------------------------------

.. py:function:: biophysics_fitting.L5tt_parameter_setup.set_param(cell_param, params=None)


   Updates cell_param given a dict of params in the dot naming convention.

   Example::

       cell_param = {'a': {'b': {'c': 2}}}
       params = {'a.b.c': 3}
       set_param(cell_param, params)
       # returns {'a': {'b': {'c': 3}}}

   :param cell_param (: py:class`~:py:class:`~single_cell_parser.parameters.NTParameterSet`` | dict): The cell parameter nested dictionary.
   :param params: The parameter flat dictionary.
   :type params: dict

   :returns: The updated cell_param.
   :rtype: dict
