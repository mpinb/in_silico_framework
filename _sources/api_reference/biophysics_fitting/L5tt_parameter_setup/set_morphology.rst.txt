.. Signature -------------------------------

.. function:: biophysics_fitting.L5tt_parameter_setup.set_morphology(cell_param, filename=None)


   Add the morphology to a cell parameter object.

   The morphology is simply a path to a :ref:`hoc_file_format` file in string format.

   :param cell_param: The cell parameter dictionary.
   :type cell_param: ~single_cell_parser.parameters.NTParameterSet
   :param filename: The path to the :ref:`hoc_file_format` file.
   :type filename: str

   :returns: The updated cell parameter dictionary.
   :rtype: :class:`~single_cell_parser.parameters.NTParameterSet` | dict
