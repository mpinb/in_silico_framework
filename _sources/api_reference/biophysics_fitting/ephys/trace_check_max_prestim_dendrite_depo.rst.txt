

trace_check_max_prestim_dendrite_depo
=====================================


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.trace_check_max_prestim_dendrite_depo(t, vmax, stim_onset, max_prestim_dendrite_depo=None)


   Check whether anywhere in the dendritic, there is a spike before stimulus onset

   :param t: Time array.
   :type t: array
   :param vmax: The voltage maximum, taken over all dendrites, at each given timepoint.
   :type vmax: array
   :param stim_onset: Time of stimulus onset (ms).
   :type stim_onset: float
   :param max_prestim_dendrite_depo: Maximum dendritic depolarization before stimulus onset (mV).
                                     If some dendrite section exceeds this value, it is considered a spike.
   :type max_prestim_dendrite_depo: float

   :returns: Whether or not a spike is detected before stimulus onset.
   :rtype: bool
