

BAC_caSpike_height_check_Ca_spikes_after_Na_spike
=================================================


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.BAC_caSpike_height_check_Ca_spikes_after_Na_spike(t, v, v_dend, n=2, thresh=None)


   Checks if a calcium spike occurs after the nth sodium spike.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of voltage values.
   :type v: numpy.ndarray
   :param v_dend: Array of dendritic voltage values.
   :type v_dend: numpy.ndarray
   :param n: The number of the sodium spike to check for.
             Defaults to 2.
   :type n: int, optional
   :param thresh: The voltage threshold for detecting spikes.
                  If None, defaults to the maximum value of v divided by 10.
                  Defaults to None.
   :type thresh: float, optional

   :returns:

             True if a calcium spike occurs after the nth sodium spike,
                 False otherwise.
   :rtype: bool
