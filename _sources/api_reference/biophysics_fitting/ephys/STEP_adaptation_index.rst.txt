.. Signature -------------------------------

.. function:: biophysics_fitting.ephys.STEP_adaptation_index(t, v, stim_end=2000, thresh=None)

   :param v: Voltage vector
   :type v: np.array
   :param stim_end: End time of the stimulus.
   :type stim_end: float

   :returns: Adaptation index.
