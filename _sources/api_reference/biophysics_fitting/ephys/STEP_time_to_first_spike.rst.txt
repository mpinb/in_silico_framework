

STEP_time_to_first_spike
========================


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.STEP_time_to_first_spike(t, v, stim_onset, thresh=None)


   Computes the time to first spike (TTFS) of a voltage trace for a step stimulus.

   .. note::

      The time to a spike is taken to be the time until the peak of the spike,
      not e.g. the peak of the second derivative.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of voltage values.
   :type v: numpy.ndarray
   :param thresh: Voltage threshold for spike detection. Defaults to None.
   :type thresh: float, optional

   :returns: Time to first spike.
   :rtype: float
