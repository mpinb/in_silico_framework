

voltage_base
============


.. Signature -------------------------------

.. function:: biophysics_fitting.ephys.voltage_base(t, v, stim_delay)


   Calculates the mean voltage between 0.5 * stim_delay and 0.75 * stim_delay.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of voltage values.
   :type v: numpy.ndarray
   :param stim_delay: Delay time of the stimulus.
   :type stim_delay: float

   :returns: Mean voltage between 0.5*stim_delay and 0.75*stim_delay.
   :rtype: float
