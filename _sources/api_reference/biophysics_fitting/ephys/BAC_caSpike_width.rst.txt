

BAC_caSpike_width
=================


.. Signature -------------------------------

.. function:: biophysics_fitting.ephys.BAC_caSpike_width(t, v, v_dend, thresh=None)


   Calculates the width of a calcium spike action potential.

   :param t: The time values of the action potential.
   :type t: array-like
   :param v: The voltage values of the action potential.
   :type v: array-like
   :param v_dend: The voltage values of the dendrite.
   :type v_dend: array-like
   :param thresh: The threshold voltage for the action potential.
   :type thresh: float, optional

   :returns: The width of the calcium spike action potential.
   :rtype: float
