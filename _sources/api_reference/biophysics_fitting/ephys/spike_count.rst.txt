

spike_count
===========


.. Signature -------------------------------

.. function:: biophysics_fitting.ephys.spike_count(t, v, thresh=None)


   Counts the number of spikes in a voltage trace.

   :param t: Time values of the voltage trace, in seconds.
   :type t: array_like
   :param v: Voltage values of the trace, in volts.
   :type v: array_like
   :param thresh: Spike detection threshold, in volts. If not specified, the threshold
                  will be set to the mean of the voltage trace.
   :type thresh: float, optional

   :returns: The number of spikes detected in the trace.
   :rtype: int
