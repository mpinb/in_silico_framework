

AP_width
========


.. Signature -------------------------------

.. function:: biophysics_fitting.ephys.AP_width(t, v, thresh)


   Calculates the action potential (AP) width given the time and voltage arrays and a threshold value.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of voltage values.
   :type v: numpy.ndarray
   :param thresh: Threshold value for detecting AP.
   :type thresh: float

   :returns: Array of AP widths.
   :rtype: numpy.ndarray
