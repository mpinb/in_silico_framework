

AP_height_check_1AP
===================


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.AP_height_check_1AP(t, v, thresh=None)


   Determines if an action potential (AP) is present in a voltage trace by checking if the voltage crosses a given threshold.

   :param t: Array of time values corresponding to the voltage trace.
   :type t: array-like
   :param v: Array of voltage values for the trace.
   :type v: array-like
   :param thresh: The voltage threshold to use for detecting the AP. If None, defaults to the maximum voltage
                  value divided by 2.
   :type thresh: float, optional

   :returns: True if at least one AP is detected in the voltage trace, False otherwise.
   :rtype: bool
