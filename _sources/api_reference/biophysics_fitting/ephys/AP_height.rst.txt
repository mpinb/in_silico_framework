

AP_height
=========


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.AP_height(t, v, thresh=None)


   Computes the amplitude of each action potential (AP) in a voltage trace.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of voltage values.
   :type v: numpy.ndarray
   :param thresh: AP threshold voltage. If None, uses the default threshold of find_crossing().
   :type thresh: float, optional

   :returns: Array of AP amplitudes.
   :rtype: numpy.ndarray
