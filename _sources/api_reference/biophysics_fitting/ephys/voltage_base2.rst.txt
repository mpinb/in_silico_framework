

voltage_base2
=============


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.voltage_base2(voltage_traces, t0, recSiteID='recSiteID')


   Fetch the voltage at a given time point t0 for a specific recording site ID.

   :param voltage_traces: A dictionary containing voltage traces for different recording sites.
   :type voltage_traces: dict
   :param recSiteID: The ID of the recording site for which the voltage is to be returned.
   :type recSiteID: int
   :param t0: The time point at which the voltage is to be returned.
   :type t0: float

   :returns: The voltage at time point t0 for the specified recording site ID.
