

STEP_check_2_ISIs
=================


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.STEP_check_2_ISIs(t, v, thresh=None)


   Check if there are more than 2 ISIs in the trace.

   calculating the adaptation index, or coefficient of variation requires at least 5 spikes (i.e. 2 ISIs) in the trace.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of voltage values.
   :type v: numpy.ndarray
   :param thresh: Voltage threshold for spike detection. Defaults to None.
   :type thresh: float, optional

   :returns: True if there are more than 2 ISIs in the trace, False otherwise.
   :rtype: bool
