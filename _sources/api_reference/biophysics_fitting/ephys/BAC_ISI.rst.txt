

BAC_ISI
=======


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.BAC_ISI(t, v, thresh=None)


   Computes the Inter-Spike Interval (ISI) of a voltage trace for a BAC stimulus.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of voltage values.
   :type v: numpy.ndarray
   :param thresh: Voltage threshold for spike detection. Defaults to None.
   :type thresh: float, optional

   :returns: Burst Averaged Inter-Spike Interval (BAC ISI) value.
   :rtype: float
