

AHP_depth_abs_check_2AP
=======================


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.AHP_depth_abs_check_2AP(t, v, thresh=None)


   Determines whether there are at least two action potentials (APs) in the voltage trace `v`
   within the time range `t` that cross the threshold `thresh`.

   :param t: The time range of the voltage trace.
   :type t: numpy.ndarray
   :param v: The voltage trace.
   :type v: numpy.ndarray
   :param thresh: The threshold voltage for detecting APs. Defaults to None.
   :type thresh: float, optional

   :returns: True if there are at least two APs in the voltage trace `v` within the time range `t`
             that cross the threshold `thresh`, False otherwise.
   :rtype: bool
