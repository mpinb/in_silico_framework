

AHP_depth_abs
=============


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.AHP_depth_abs(t, v, thresh=None)


   Calculates the absolute afterhyperpolarization (AHP) depth for a given voltage trace.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of voltage values.
   :type v: numpy.ndarray
   :param thresh: Threshold voltage for action potential detection. Defaults to None.
   :type thresh: float, optional

   :returns: Array of AHP depths, one for each action potential in the voltage trace.
   :rtype: numpy.ndarray
