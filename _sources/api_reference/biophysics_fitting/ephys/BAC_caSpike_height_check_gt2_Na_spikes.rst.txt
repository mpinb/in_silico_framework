

BAC_caSpike_height_check_gt2_Na_spikes
======================================


.. Signature -------------------------------

.. function:: biophysics_fitting.ephys.BAC_caSpike_height_check_gt2_Na_spikes(t, v, v_dend, thresh=None)


   Checks if the number of spikes in the voltage trace is greater than or equal to 2.

   :param t: Array of time values.
   :type t: array
   :param v: Array of voltage values.
   :type v: array
   :param v_dend: Array of dendritic voltage values.
   :type v_dend: array
   :param thresh: Spike detection threshold. Defaults to None.
   :type thresh: float, optional

   :returns: True if the number of spikes is greater than or equal to 2, False otherwise.
   :rtype: bool
