

BAC_ISI_check_repolarization
============================


.. Signature -------------------------------

.. function:: biophysics_fitting.ephys.BAC_ISI_check_repolarization(t, v, stim_end=None, repolarization=None)


   Checks if the membrane potential has repolarized to a certain value after a stimulus for a BAC stimulus.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of membrane potential values.
   :type v: numpy.ndarray
   :param stim_end: Time at which the stimulus ends. Defaults to None.
   :type stim_end: float, optional
   :param repolarization: Value to which the membrane potential should repolarize. Defaults to None.
   :type repolarization: float, optional

   :returns: True if the membrane potential has repolarized to the specified value, False otherwise.
   :rtype: bool
