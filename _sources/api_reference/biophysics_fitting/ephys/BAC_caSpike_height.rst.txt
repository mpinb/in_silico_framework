

BAC_caSpike_height
==================


.. Signature -------------------------------

.. function:: biophysics_fitting.ephys.BAC_caSpike_height(t, v, v_dend, ca_thresh=-55, tstim=295)


   Returns the height of the calcium spike after tstim.

   :param t: Time array.
   :type t: array-like
   :param v: Voltage array.
   :type v: array-like
   :param v_dend: Dendritic voltage array.
   :type v_dend: array-like
   :param ca_thresh: Calcium threshold. Defaults to -55.
   :type ca_thresh: float, optional
   :param tstim: Time of stimulation. Defaults to 295.
   :type tstim: float, optional

   :returns: Height of the calcium spike.
   :rtype: float
