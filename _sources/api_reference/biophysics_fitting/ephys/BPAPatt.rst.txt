

BPAPatt
=======


.. Signature -------------------------------

.. py:function:: biophysics_fitting.ephys.BPAPatt(t, v_dend, thresh='+2mV', stim_onset=None)


   Computes the amplitude of the backpropagating action potential (bAP) at the dendrite.

   :param t: Time array.
   :type t: array
   :param v_dend: Dendritic voltage array.
   :type v_dend: array
   :param thresh: Threshold voltage for detecting the bAP. Default is '+2mV'.
   :type thresh: str or float
   :param stim_onset: Time of the stimulus onset. Default is ``None``.
   :type stim_onset: float

   :returns: Amplitude of the bAP at the dendrite.
   :rtype: float
