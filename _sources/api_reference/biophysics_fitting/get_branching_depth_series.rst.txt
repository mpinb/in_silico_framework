

get_branching_depth_series
==========================


.. Signature -------------------------------

.. function:: biophysics_fitting.get_branching_depth_series(cell, z_offset=706)


   Find the branching depth of the inner sections of a :class:`~single_cell_parser.cell.Cell`.

   :param cell: The Cell object
   :type cell: ~single_cell_parser.cell.Cell
   :param z_offset: Z coordinate offset for :func:`get_inner_sec_dist_list`.
                    Defaults to 706 um.
   :type z_offset: int | float, optional

   :returns: contains the distance to :param:`z_offset` as index and a tuple (branching depth, section) as value
   :rtype: pd.Series

   .. note:: Careful: z-depth only accurate for D2-registered cells!
