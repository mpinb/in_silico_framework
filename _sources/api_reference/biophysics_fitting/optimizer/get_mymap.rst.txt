

get_mymap
=========


.. Signature -------------------------------

.. py:function:: biophysics_fitting.optimizer.get_mymap(db_setup, db_run, c, satisfactory_boundary_dict=None, n_reschedule_on_runtime_error=3)


   Get a map function for evaluating the parameters.

   This function is a hook into BluePyOpt's optimization.
   It is used as a mapping function in :py:class:`bluepyopt.optimisations.DEAPOptimisation` during :py:meth:`start_run`.
   Rather than just returning the combined objectives, it also saves the features and the objectives in the database.
   This is useful for debugging and for analyzing the optimization results.

   :param db_setup: Database containing the setup of the optimization.
   :type db_setup: ~data_base.DataBase
   :param db_run: The database for the optimization run containing sub-databases.
   :type db_run: ~data_base.DataBase
   :param c: The distributed client.
   :type c: ~dask.distributed.Client
   :param satisfactory_boundary_dict: A dictionary with the boundaries for the objectives. If a model is found, that has all objectives below the boundary, the optimization is stopped.
   :type satisfactory_boundary_dict: dict | None
   :param n_reschedule_on_runtime_error: The number of times the optimization is rescheduled if a runtime error occurs.
   :type n_reschedule_on_runtime_error: int

   :returns: The map function for evaluating the parameters. this function is passed to the :py:class:`bluepyopt.optimisations.DEAPOptimisation` object.
   :rtype: Callable
