

get_max_generation
==================


.. Signature -------------------------------

.. function:: biophysics_fitting.optimizer.get_max_generation(db_run)


   Returns the index of the next iteration in a database.
   If the database is empty, it returns -1.

   :param db_run: The database.
   :type db_run: data_base.DataBase

   :returns: The index of the next iteration. If the database is empty, it returns -1.
   :rtype: int
