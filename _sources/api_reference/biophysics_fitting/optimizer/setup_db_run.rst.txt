

setup_db_run
============


.. Signature -------------------------------

.. py:function:: biophysics_fitting.optimizer.setup_db_run(db_setup, run)


   Create a sub-database for each run of the optimization algorithm.
   db_setup contains a sub db for each run of the full optimization. This sub db is created here.

   :param db_setup: The database containing the setup of the optimization.
   :type db_setup: data_base.DataBase
   :param run: The index of the optimization run.
   :type run: int

   :returns: The database for the optimization run containing sub-databases..
   :rtype: data_base.DataBase
