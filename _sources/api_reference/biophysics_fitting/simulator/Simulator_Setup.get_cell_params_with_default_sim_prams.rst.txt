

get_cell_params_with_default_sim_prams
======================================


.. Signature -------------------------------

.. function:: biophysics_fitting.simulator.Simulator_Setup.get_cell_params_with_default_sim_prams(params, recordingSites=[], tStart=0.0, tStop=295, dt=0.025, Vinit=-75.0, T=34.0)


   Get a neuron parameter object.

   Constructs a complete neuron parameter object that can be used for further simulations with e.g. :mod:`simrun`.

   :param params: The parameter vector.
   :type params: pd.Series
   :param recordingSites: The recording site (um).
   :type recordingSites: [float]
   :param tStart: The start time of the simulation (ms).
   :type tStart: float
   :param tStop: The stop time of the simulation (ms).
   :type tStop: float
   :param dt: The time step of the simulation (ms).
   :type dt: float
   :param Vinit: The initial voltage (mV).
   :type Vinit: float
   :param T: The temperature (Celsius).
   :type T: float

   :returns: The neuron parameter object.
   :rtype: :class:`~single_cell_parser.parameters.NTParameterSet`
