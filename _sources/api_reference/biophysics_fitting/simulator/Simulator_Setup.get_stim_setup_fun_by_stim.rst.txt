

get_stim_setup_fun_by_stim
==========================


.. Signature -------------------------------

.. function:: biophysics_fitting.simulator.Simulator_Setup.get_stim_setup_fun_by_stim(stim)


   Get the stimulus setup function by stimulus name.

   Stimulus setup functions are functions that set up the stimulus.
   They are saved under the name ``stimulus_name.setup``, and accessible
   under :param:`stim_setup_funs`.

   :param stim: The stimulus name, e.g. ``'stim_1'``, ``'bAP'``, ``'StepOne'``.
   :type stim: str

   :returns: The setup function for the stimulus.
   :rtype: Callable
