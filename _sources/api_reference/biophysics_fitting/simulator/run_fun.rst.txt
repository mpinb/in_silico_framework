

run_fun
=======


.. Signature -------------------------------

.. py:function:: biophysics_fitting.simulator.run_fun(cell, T=34.0, Vinit=-75.0, dt=0.025, recordingSites=[], tStart=0.0, tStop=250.0, vardt=True, silent=True)


   Default function to run a simulation.

   :param cell: The cell object.
   :param T: The temperature (Celsius).
   :type T: float
   :param Vinit: The initial voltage (mV).
   :type Vinit: float
   :param dt: The time step (ms).
   :type dt: float
   :param recordingSites: The recording sites (um).
   :type recordingSites: [float]
   :param tStart: The start time of the simulation (ms).
   :type tStart: float
   :param tStop: The stop time of the simulation (ms).
   :type tStop: float
   :param vardt: Whether to use variable time step.
   :type vardt: bool
   :param silent: Whether to suppress output.
   :type silent: bool

   :returns: The cell object, containing simulation data.
   :rtype: :py:class:`~single_cell_parser.cell.Cell`
