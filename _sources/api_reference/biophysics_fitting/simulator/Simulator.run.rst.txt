




Simulator.run
=============


.. py:method:: biophysics_fitting.simulator.Simulator.run(params, stims=None)


   Simulates all stimuli for a given parameter vector.

   :param params: The parameter vector.
   :param stims: which sitmuli to run. Either a str (for one stimulus) or a list of str.
   :type stims: str | [str]

   :returns: Dictionary where stim_response_measure_funs names are keys,
             return values of the stim_response_measure_funs (usually voltage traces) are values.
   :rtype: dict
