

_check_not_none
===============


.. Signature -------------------------------

.. function:: biophysics_fitting.simulator.Simulator_Setup._check_not_none(var, varname, procedure_description)


   Convenience method to check if the output of some method is not None.

   Used as sanity check throughout this class.

   :param var: The variable to check.
   :param varname: The name of the variable.
   :type varname: str
   :param procedure_description: A description of the procedure that produced the variable.
   :type procedure_description: str

   :raises ValueError: If :param:`var` is None.
