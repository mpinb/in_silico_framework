

get_first_order_bifurcation_sections
====================================


.. Signature -------------------------------

.. function:: biophysics_fitting.get_first_order_bifurcation_sections(cell)


   Find all sections that are both inner sections, and are of branching order 1.

   :param cell: The Cell object for which to find the main bifurcation section.
   :type cell: ~single_cell_parser.cell.Cell

   :returns: A list of :class:`~single_cell_parser.cell.PySection` sections that are both inner sections, and are of branching order 1.
   :rtype: list
