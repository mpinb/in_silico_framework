

change_ongoing_interval
=======================


.. Signature -------------------------------

.. function:: single_cell_parser.network_param_modify_functions.change_ongoing_interval(n, factor=1, pop=None)


   Scales the ongoing frequency with a :paramref:`factor`.

   Does so by scaling the time bins of the ongoing activity of the presynaptic :py:class:`~single_cell_parser.celltypes.Spiketrain` celltype.

   :param n: The :ref:`network_parameters_format`.
   :type n: ~single_cell_parser.parameters.NTParameterSet
   :param factor: The factor to scale the ongoing frequency with.
   :type factor: float
   :param pop: The celltypes to apply the scaling to.
   :type pop: list

   :raises AssertionError: If the presynptic :py:class:`~single_cell_parser.celltypes.PointCell` is not of type ``spiketrain``.

   .. rubric:: Example
      :class: example

   >>> celltype = 'L6cc_C2'  # layer 6 cortico-cortical cells in column C2
   >>> n.network[celltype].celltype.pointcell.intervals
   [(0, 1000)]
   >>> change_ongoing_interval(n, 2, pop=['L6cc'])
   >>> n.network[celltype].celltype.pointcell.intervals
   [(0, 2000)]
