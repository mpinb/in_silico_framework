

change_evoked_INH_scaling
=========================


.. Signature -------------------------------

.. py:function:: single_cell_parser.network_param_modify_functions.change_evoked_INH_scaling(param, factor, pop=INHIBITORY)


   Scales the response probability for inhibitory cells in the :ref:`network_parameters_format`.

   :param param: The :ref:`network_parameters_format`.
   :type param: ~single_cell_parser.parameters.NTParameterSet
   :param factor: The scaling factor.
   :type factor: float
   :param pop: The celltypes to apply the scaling to.
               Default is the inhibitory celltypes in the rat somatosensory cortex vS1.
   :type pop: list
