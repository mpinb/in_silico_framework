

set_stim_onset
==============


.. Signature -------------------------------

.. py:function:: single_cell_parser.network_param_modify_functions.set_stim_onset(n, onset=None)


   Changes the offset when pointcells get activated

   :param n: The :ref:`network_parameters_format`.
   :type n: ~single_cell_parser.parameters.NTParameterSet
   :param onset: The onset time in milliseconds.
   :type onset: float

   .. rubric:: Example
      :class: example

   >>> celltype = 'L6cc_C2'  # layer 6 cortico-cortical cells in column C2
   >>> n.network[celltype].celltype.pointcell.offset
   0
   >>> set_stim_onset(n, 100)
   >>> n.network[celltype].celltype.pointcell.offset
   100
