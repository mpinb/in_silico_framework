

multi_stimulus_trial
====================


.. Signature -------------------------------

.. function:: single_cell_parser.network_param_modify_functions.multi_stimulus_trial(netp, inter_stimulus_interval=100, stims=100, scale_factors=None, pop=None)


   Makes a network param file for repeatedly stimulating the same whisker during a single trial.

   Optionally applies a different evoked activity scaling factor to each stimulus.

   :param netp: The :ref:`network_parameters_format`.
   :type netp: ~single_cell_parser.parameters.NTParameterSet
   :param inter_stimulus_interval: amount of time to wait (in ms) between each whisker stimulus
   :type inter_stimulus_interval: int | float
   :param stims: number of stimuli to simulate
   :type stims: int
   :param scale_factors: A list of scale factors you want to apply to subsequent stimuli.
                         Must have the same length as stims.
   :type scale_factors: list, optional
   :param pop: The celltypes you would like the scaling to be applied to.
   :type pop: list, optional
