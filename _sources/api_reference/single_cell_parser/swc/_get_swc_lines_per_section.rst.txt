

_get_swc_lines_per_section
==========================


.. Signature -------------------------------

.. function:: single_cell_parser.swc._get_swc_lines_per_section(cell, skip_myelin=False, remap_sections=None)


   Write out a cell object to swc format::

       index type x y z radius parent

   :param cell: A cell object.
                Must contain the ``sections`` attribute returning a generator for NEURON sections.
   :type cell: single_cell_parser.cell.Cell
   :param skip_myelin: If True, myelin will not be written to the resulting .swc file.
   :type skip_myelin: bool
   :param remap_sections: A dictionary mapping section indices to a custom label.
                          Custom labels can often be re-assigned to a type of choice anyways after loading the SWC morphology.
                          This feature is useful for temporarily remapping the label of same-type only-child sections, preserving
                          the fact that they are different sections in SWC.
   :type remap_sections: dict

   :returns:     Nested list of swc lines (index, type, x, y, z, radius, parent), organized per section.
   :rtype: List[List[List]]
