

write_sim_results
=================


.. Signature -------------------------------

.. function:: single_cell_parser.writer.write_sim_results(fname, t, v)


   Write out a voltage trace file.

   :param fname: The name of the file to write to.
   :type fname: str
   :param t: The time points of the voltage trace.
   :type t: list
   :param v: The voltage trace.
   :type v: list

   :returns: None. Writes out the voltage trace file to :param:`fname`.

   .. rubric:: Example
      :class: example

   >>> t = [0.0, 0.1, 0.2]
   >>> v = [-65.0, -64.9, -64.8]
   >>> write_sim_results('voltage_trace.dat', t, v)
