

write_functional_map
====================


.. Signature -------------------------------

.. py:function:: single_cell_parser.writer.write_functional_map(fname, functionalMap)


   Write a functional map to an AMIRA file.

   Deprecated. Consider using :py:meth:`visualize.vtk.write_vtk_pointcloud_file`
   or :py:meth:`visualize.vtk.write_vtk_frames` for visualization purposes.

   This method may still serve well if you need an AMIRA mesh file.

   :param fname: The name of the file to write to.
   :type fname: str
   :param functionalMap: A dictionary with cell labels as keys and lists of points as values.
   :type functionalMap: dict

   :returns: None. Writes out the functional map file to :paramref:`fname`.
