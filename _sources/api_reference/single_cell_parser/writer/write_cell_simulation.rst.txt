

write_cell_simulation
=====================


.. Signature -------------------------------

.. py:function:: single_cell_parser.writer.write_cell_simulation(fname=None, cell=None, traces=None, tVec=None, allPoints=False, step_frames=10, selected_index=None)


   Write Amira SpatialGraph files corresponding to time steps of entire simulation run.

   Recorded quantities are passed in tuple traces with strings and recorded in Vectors
   attached to Sections of cell

   .. attention:: Make sure to have created the cell with ``allPoints = True``.

   .. attention:: Performs interpolation if ``nseg != nrOfPts`` for a Section

   :param fname: The name of the file to write to.
   :type fname: str
   :param cell: The cell object.
   :type cell: single_cell_parser.cell.Cell
   :param traces: A list of strings, each representing a recorded quantity.
   :type traces: list
   :param tVec: A list of time points.
   :type tVec: list
   :param allPoints: If True, all points of the cell are written to the file.
   :type allPoints: bool
   :param step_frames: The number of frames to write.
   :type step_frames: int
   :param selected_index: A list of indices of the sections to write.
   :type selected_index: list

   Example:

   >>> write_cell_simulation(
   ...     '/output/directory',
   ...     cell = cell,
   ...     traces = ['Vm'],
   ...     tVec = cell.tVec,
   ...     step_frames = 1,
   ...     selected_index=[selected_index],
   ...     allPoints = True)
