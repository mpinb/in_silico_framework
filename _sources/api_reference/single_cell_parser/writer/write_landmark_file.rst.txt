

write_landmark_file
===================


.. Signature -------------------------------

.. function:: single_cell_parser.writer.write_landmark_file(fname=None, landmarkList=None)


   Write an AMIRA landmark file from 3D coordinates

   :param fname: string, name of the output file
   :type fname: str
   :param landmarkList: list of tuples, each of which holds 3 float coordinates
   :type landmarkList: list

   :returns: None. Writes out the landmark file to :param:`fname`

   :raises RuntimeError: if no file name is given or if the landmark list is empty
   :raises RuntimeError: if the landmarks have the wrong format (not 3 coordinates)

   .. rubric:: Example
      :class: example

   >>> landmarkList = [(0.0, 0.0, 0.0), (1.0, 1.0, 1.0)]
   >>> write_landmark_file('landmarks.landmarkAscii', landmarkList)
