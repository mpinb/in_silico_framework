

write_all_traces
================


.. Signature -------------------------------

.. function:: single_cell_parser.io.activity.write_all_traces(fname, t, vTraces)


   Write out a list of voltage traces.

   :param fname: The name of the file to write to.
   :type fname: str
   :param t: The time points of the voltage traces.
   :type t: list
   :param vTraces: A list of voltage traces.
   :type vTraces: list

   :returns: None. Writes out the voltage traces to :param:`fname`.

   .. rubric:: Example
      :class: example

   >>> t = [0.0, 0.1, 0.2]
   >>> vTraces = [[-65.0, -64.9, -64.8], [-70.0, -69.9, -69.8]]
   >>> write_all_traces('voltage_traces.dat', t, vTraces)
