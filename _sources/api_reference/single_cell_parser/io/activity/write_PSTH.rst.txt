

write_PSTH
==========


.. Signature -------------------------------

.. function:: single_cell_parser.io.activity.write_PSTH(fname=None, PSTH=None, bins=None)


   Write PSTH and time bins of PSTH,

   Bins contain left and right end of each bin, i.e. ``len(bins) = len(PSTH) + 1``

   :param fname: The name of the file to write to.
   :type fname: str
   :param PSTH: A list of PSTH values.
   :type PSTH: list
   :param bins: A list of time bins, including begin and end
   :type bins: list

   :returns: None. Writes out the PSTH file to :param:`fname`.

   .. rubric:: Example
      :class: example

   >>> PSTH = [1, 1, 2]
   >>> bins = [0.0, 0.1, 0.2, 0.3]
   >>> write_PSTH('PSTH.param', PSTH, bins)
   >>> PSTH.param
   # bin begin     bin end APs/trial/bin
   0.0     0.1     1
   0.1     0.2     1
   0.2     0.3     2
