

write_spike_times_file
======================


.. Signature -------------------------------

.. function:: single_cell_parser.io.activity.write_spike_times_file(fname=None, spikeTimes=None)


   Write trial numbers and all spike times in each trial (may be empty).

   :param fname: The name of the file to write to.
   :type fname: str
   :param spikeTimes: A dictionary with trial numbers as keys (int) and tuples of spike times in each trial as values.
   :type spikeTimes: dict

   :returns: None. Writes out the spike times file to :param:`fname`.

   .. rubric:: Example
      :class: example

   >>> spikeTimes = {0: [0.1, 0.2, 0.3], 1: [], 2: [0.2, 0.3]}
   >>> write_spike_times_file('spike_times.param', spikeTimes)
   >>> spike_times.param
   # trial spike times
   0       0.1,0.2,0.3,
   1
   2       0.2,0.3,
