.. Signature -------------------------------

.. function:: single_cell_parser.parameters.resolve_parameter_paths(parameters, params_fn)


   Resolve relative database paths in the parameters.

   :param parameters: The parameters whose internal paths need to be resolved to the new database location.
   :type parameters: single_cell_parser.parameters.NTParameterSet
   :param params_fn: The path to the parameters file.
   :type params_fn: str

   :returns: The parameters with resolved paths.
   :rtype: :class:`~single_cell_parser.parameters.NTParameterSet`
