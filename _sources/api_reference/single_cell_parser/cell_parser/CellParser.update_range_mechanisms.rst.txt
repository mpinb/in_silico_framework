

update_range_mechanisms
=======================


.. Signature -------------------------------

.. function:: single_cell_parser.cell_parser.CellParser.update_range_mechanisms(label, updateMechName, mechs)


   Updates range mechanism :param:`updateMechName` in all structures named as :param:`label`.

   This method is essentially the same as insert_range_mechanisms, but does not
   insert mechanisms. Instead assumes they're already present.

   Used during parameter variations; e.g. for optimization and exploration of neuron models (see :mod:`biophysics_fitting`).

   :param label: Label of the structure.
   :type label: str
   :param updateMechName: Name of the mechanism to update.
   :type updateMechName: str
   :param mechs: Range mechanisms. Must contain the key ``spatial`` to define the spatial distribution. Possible values for spatial distributions are given in :func:`insert_range_mechanisms`.
   :type mechs: ~single_cell_parser.parameters.NTParameterSet

   :raises RuntimeError: If the structure has not been parsed from the :ref:`hoc_file_format` file yet.
   :raises NotImplementedError: If the spatial distribution is not implemented.
