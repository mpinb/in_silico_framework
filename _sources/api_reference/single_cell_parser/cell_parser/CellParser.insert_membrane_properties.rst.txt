




CellParser.insert_membrane_properties
=====================================


.. py:method:: single_cell_parser.cell_parser.CellParser.insert_membrane_properties(label, props)


   Inserts membrane properties into all structures named as :paramref:`label`.

   :param label: Label of the structure.
   :type label: str
   :param props: Membrane properties.
                 Keys named ``spines`` or ``ions`` are ignored,
                 as they are taken care of by :py:meth:`insert_range_mechanisms` and :py:meth:`_insert_ion_properties`.
   :type props: ~single_cell_parser.parameters.NTParameterSet

   :raises RuntimeError: If the structure has not been parsed from the :ref:`hoc_file_format` file yet.
