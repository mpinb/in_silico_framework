

compute_syn_distance
====================


.. Signature -------------------------------

.. function:: single_cell_parser.analyze.synanalysis.compute_syn_distance(cell, syn, consider_gap_to_soma=False)


   Computes the distance from a single synapse to the soma.

   Used in :func:`compute_syn_distances`.

   :param cell: cell object with attached synapses.
   :type cell: single_cell_parser.cell.Cell
   :param syn: synapse object.
   :type syn: single_cell_parser.synapse.Synapse
   :param consider_gap_to_soma: Account for the fact that dendrites don't actually touch the soma, and add the
                                distance between the last point of the parent section and the first point of the
                                current section to the distance.
                                Default: False
   :type consider_gap_to_soma: bool, optional
