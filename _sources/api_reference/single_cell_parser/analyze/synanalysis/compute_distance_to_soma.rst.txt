

compute_distance_to_soma
========================


.. Signature -------------------------------

.. py:function:: single_cell_parser.analyze.synanalysis.compute_distance_to_soma(sec, x, cell=None, consider_gap_to_soma=False)


   Computes the distance from a point to the soma.

   The point for which to compute the distance is defined by a section
   and a relative point on that section (the x coordinate between 0 and 1).

   Used in :py:meth:`compute_syn_distance` and :py:meth:`compute_syn_distances`.

   :param sec: Section or section ID of the cell.
               If the section ID is given, :paramref:`cell` must be provided.
   :type sec: single_cell_parser.cell.PySection
   :param x: Relative point on section, from 0 to 1.
   :type x: float
   :param cell: Only required if :paramref:`sec` is the section ID.
   :type cell: single_cell_parser.cell.Cell
   :param consider_gap_to_soma: Accounts for the fact that dendrites don't actually touch the soma, and adds the
                                distance between the last point of the parent section and the first point of the
                                current section to the distance.
                                Default: False
   :type consider_gap_to_soma: bool, optional

   :returns: distance to the soma
   :rtype: float
