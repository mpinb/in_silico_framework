

set_up_recording_site
=====================


.. Signature -------------------------------

.. function:: single_cell_parser.analyze.membrane_potential_analysis.RecordingSiteManager.set_up_recording_site(location, ID, filename)


   Set up a :class:`RecordingSite` from a location.

   Determines the section and segment on the cell corresponding
   to the recording site location and creates new :class:`RecordingSite`.

   Used during initialization.

   :param location: Location of the recording site.
   :type location: numpy.ndarray
   :param ID: ID of the recording site.
   :type ID: int
   :param filename: Path to the AMIRA landmark file containing all recording sites.
   :type filename: str
