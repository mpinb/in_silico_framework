

compute_vm_std_windows
======================


.. Signature -------------------------------

.. function:: single_cell_parser.analyze.membrane_potential_analysis.compute_vm_std_windows(vStd, tStim, dt, width=35.0, window_start_times=None)


   Compute the standard deviation of the voltage during different time windows.

   :param vStd: List of standard deviations of the voltage
   :type vStd: list
   :param tStim: Time of stimulation
   :type tStim: float
   :param dt: Time step.
   :type dt: float
   :param width: Width of each time window. Default is :math:`35.0 ms`.
   :type width: float
   :param window_start_times: List of start times for the time windows. Default is ``[-50.0, 15.0]``.
   :type window_start_times: list

   :returns: A tuple containing the time windows and the average standard deviations.
   :rtype: tuple
