

PSTH_from_spike_times
=====================


.. Signature -------------------------------

.. py:function:: single_cell_parser.analyze.membrane_potential_analysis.PSTH_from_spike_times(spikeTimeVectors, binSize=1.0, tBegin=None, tEnd=None, aligned=True)


   Calculates a PSTH from spike times.

   :param spikeTimeVectors: List of spike time vectors.
   :type spikeTimeVectors: list
   :param binSize: Bin size for the PSTH. Default is `1.0 ms`.
   :type binSize: float, optional
   :param tBegin: Start time of the PSTH. Default is ``None`` (min of :paramref:`spikeTimeVectors`).
   :type tBegin: float, optional
   :param tEnd: End time of the PSTH. Default is ``None`` (max of :paramref:`spikeTimeVectors`).
   :type tEnd: float, optional
   :param aligned: If True, aligns the bins to integer multiples of the bin size. Default is ``True``.
   :type aligned: bool, optional

   :returns: Tuple containing the histogram and the bins.
   :rtype: tuple
