




SpikeInit.vm_steady_state
=========================


.. py:method:: single_cell_parser.analyze.membrane_potential_analysis.SpikeInit.vm_steady_state(cell, tVec, tStim, dtStim)

   :staticmethod:


   Computes the "steady-state" voltage

   The steady-state voltage is the median voltage during a stimulation time window.
   This can be used to define a voltage spike threshold at current intensities just below AP initiation.

   :param cell: Cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param tVec: Time vector.
   :type tVec: list
   :param tStim: Start time of stimulation.
   :type tStim: float
   :param dtStim: Duration of stimulation.
   :type dtStim: float

   :returns: Steady-state voltage during :math:`[tStim, tStim+dtStim]`.
   :rtype: float
