

_intersect_bboxes
=================


.. Signature -------------------------------

.. function:: single_cell_parser.synapse_mapper.SynapseMapper._intersect_bboxes(bbox1, bbox2)


   Check if two bounding boxes overlap

   :param bbox1: Bounding box of the first object (minx, maxx, miny, maxy, minz, maxz).
   :type bbox1: tuple
   :param bbox2: Bounding box of the second object (minx, maxx, miny, maxy, minz, maxz).
   :type bbox2: tuple

   :returns: True if the bounding boxes overlap, False otherwise.
   :rtype: bool
