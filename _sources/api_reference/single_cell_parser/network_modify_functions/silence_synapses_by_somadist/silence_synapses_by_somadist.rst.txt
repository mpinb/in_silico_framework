

silence_synapses_by_somadist
============================


.. Signature -------------------------------

.. py:function:: single_cell_parser.network_modify_functions.silence_synapses_by_somadist.silence_synapses_by_somadist(cell, evokedNW, soma_dist_ranges=None)


   Silence synapses at a certain soma distance.

   :param cell: The cell to modify.
   :type cell: single_cell_parser.cell.Cell
   :param soma_dist_ranges: Dictionary with synapse types as keys (e.g. L5tt_C2) and the range
                            in which it should be silenced as value.
   :type soma_dist_ranges: dict

   .. rubric:: Example
      :class: example

   >>> soma_dist_ranges = {
   ... 'VPM_C2': [0,200],
   ... 'L5tt_C2': [1000,1200]
   ... }
