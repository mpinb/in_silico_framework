

re_init_network
===============


.. Signature -------------------------------

.. function:: single_cell_parser.network.NetworkMapper.re_init_network(replayMode=False)


   Reinitialize the network for a new simulation run.

   Sets all the presynaptic cells to ``off``.

   .. seealso:: :func:`~single_cell_parser.cell.PointCell.turn_off` for more information on turning cells off.

   :param replayMode: Whether or not to destroy the presynaptic cells as well. Default: False.
                      Set to False if you want to keep the presynaptic cells for a new simulation run.
                      Set to True if you want to recreate a new network realization (not taken care of in this function).
   :type replayMode: bool
