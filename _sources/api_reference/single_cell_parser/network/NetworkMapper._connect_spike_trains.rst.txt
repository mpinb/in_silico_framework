

_connect_spike_trains
=====================


.. Signature -------------------------------

.. function:: single_cell_parser.network.NetworkMapper._connect_spike_trains(weights=None, change=None)


   Connects synapses with spike generators.

   Spike trains are activity sources with given mean spike rate (SpikeTrains).
   All synapses are independent.

   Used in :func:`create_network`.
