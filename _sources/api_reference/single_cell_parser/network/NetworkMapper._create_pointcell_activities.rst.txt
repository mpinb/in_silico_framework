

_create_pointcell_activities
============================


.. Signature -------------------------------

.. function:: single_cell_parser.network.NetworkMapper._create_pointcell_activities(preCellType, networkParameters)


   Create point cell spike times based on the network parameters ``distribution`` keyword.

   Depending on the ``distribution`` given by :param:`networkParameters`, this method creates
   spike times for each presynaptic cell of type :param:`preCellType`.

   The following spike time distributions are supported, and require the following parameters:

   .. list-table:: Spike Time Distributions
      :header-rows: 1

      * - Distribution Type
        - Parameters
      * - "normal"
        - "spikeT", "spikeWidth", "offset", "activeFrac" (optional, default=1)
      * - "uniform"
        - "window", "offset", "activeFrac" (optional, default=1)
      * - "lognormal"
        - "mu", "sigma", "offset", "activeFrac" (optional, default=1)
      * - "PSTH"
        - "intervals", "probabilities", "offset"
      * - "PSTH_absolute_number"
        - "intervals", "number_active_synapses", "offset"
      * - "PSTH_poissontrain" (deprecated)
        - "intervals", "rates", "offset"
      * - "PSTH_poissontrain_v2"
        - "bins", "rates", "offset"
      * - "poissontrain_modulated"
        - "rate_before_t_offset", "mean_rate", "max_modulation", "modulation_frequency", "bin_size", "phase_distribution", "offset"

   See :ref:`network_parameters_format` for more information on the network parameter file format.

   :param preCellType: The presynaptic cell type.
   :type preCellType: str
   :param networkParameters: The network parameters for the presynaptic cell type.
   :type networkParameters: ~single_cell_parser.parameters.NTParameterSet

   :returns: None
