

activate_hoc_syn
================


.. Signature -------------------------------

.. function:: single_cell_parser.synapse.ExSyn.activate_hoc_syn(source, targetCell, threshold=10.0, delay=0.0, weight=0.0)


   Setup of all necessary hoc connections.

   Stores all mechanisms and NetCons for reference counting.

   :param source: Presynaptic cell whose :attr:`single_cell_parser.cell.PointCell.spikes` attribute is used as ``source`` in NEURON's NetCon object.
                  Note that in the context of a synapse, ``spikes`` means release times, which is not necessarily the same as the presynaptic spike times.
   :type source: single_cell_parser.cell.PointCell
   :param targetCell: Postsynaptic cell.
   :type targetCell: single_cell_parser.cell.Cell
   :param threshold: Activation threshold. default is :math:`10mV`
   :type threshold: float
   :param delay: Delay between the activation of the presynaptic cell and the synapse. Default is :math:`0ms`
   :type delay: float
   :param weight: Weight of the synapse.
   :type weight: float
