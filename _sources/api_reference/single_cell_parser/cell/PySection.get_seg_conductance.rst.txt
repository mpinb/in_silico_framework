




PySection.get_seg_conductance
=============================


.. py:method:: single_cell_parser.cell.PySection.get_seg_conductance(seg, var, param_name)


   Get the conductance of a segment.

   Given a segment and a variable name, this function retrieves the conductance of the specified variable in the segment.

   :param seg: The segment to retrieve the conductance from.
   :type seg: neuron.nrn.Segment
   :param var: The variable name of the mechanism e.g. ``NaTa_t``.
   :type var: str
   :param param_name: The parameter name of the mechanism e.g. ``gNaTa_tbar``.
   :type param_name: str

   :returns: The conductance of the specified variable in the segment.
   :rtype: float

   :raises ValueError: If the segment does not have the specified variable.

   :raises AssertionError: If the segment is not an instance of :py:class:`neuron.nrn.Segment`.
