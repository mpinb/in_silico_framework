

_init_range_var_recording
=========================


.. Signature -------------------------------

.. function:: single_cell_parser.cell.PySection._init_range_var_recording(var, mech=None)


   Initialize recording of a range mechanism.

   :param var: The name of the range mechanism to record.
   :type var: str
   :param mech: The name of the mechanism. Defaults to None.
   :type mech: str, optional

   :raises NameError: If the mechanism is not present in the segment.
   :raises AttributeError: If the mechanism is not present in the segment.

   .. rubric:: Example
      :class: example

   >>> sec._init_range_var_recording('ica', 'Ca_HVA')
