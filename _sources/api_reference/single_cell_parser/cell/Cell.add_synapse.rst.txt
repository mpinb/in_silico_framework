

add_synapse
===========


.. Signature -------------------------------

.. function:: single_cell_parser.cell.Cell.add_synapse(secID, ptID, ptx, preType='Generic', postType='Generic')


   Add a :class:`~single_cell_parser.synapse.Synapse` to the cell object.

   :param secID: The section ID of the synapse location.
   :type secID: int
   :param ptID: The point ID of the synapse location.
   :type ptID: int
   :param ptx: The relative coordinate along the section.
   :type ptx: float
   :param preType: The presynaptic cell type. Defaults to 'Generic'.
   :type preType: str, optional
   :param postType: The postsynaptic cell type. Defaults to 'Generic'.
   :type postType: str, optional

   :returns: The newly created synapse.
   :rtype: :class:`~single_cell_parser.synapse.Synapse`
