

get_synapse_activation_dataframe
================================


.. Signature -------------------------------

.. function:: single_cell_parser.cell.Cell.get_synapse_activation_dataframe(max_spikes=20, sim_trial_index=0)


   Get a :ref:`syn_activation_format` dataframe.

   The :ref:`syn_activation_format` dataframe contains:

   - Synapse ID
   - Synapse type (i.e. presynaptic origin)
   - Synapse location: soma distance, section ID, section point ID, and dendrite label of the synapse
   - Activation times
   - The simulation trial index

   :param max_spikes: The maximum number of spikes (i.e. synaptic activations, not necessarily the same as spikes of the presynaptic cell) to write out. Defaults to 20.
   :type max_spikes: int, optional
   :param sim_trial_index: The index of the simulation trial. Defaults to 0.
   :type sim_trial_index: int, optional

   :returns: The synapse activation dataframe.
   :rtype: pandas.DataFrame
