

distance_to_soma
================


.. Signature -------------------------------

.. function:: single_cell_parser.cell.Cell.distance_to_soma(sec, x)


   Computes the path length between the soma and a specified point.

   The point is specified by its location :paramref:`x` in the section :paramref:`sec`, or by the point ID :paramref:`x` and section ID :paramref:`sec`.

   :param sec: Section or section ID containing the point.
   :type sec: Section | int
   :param x: Location or point ID of the point.
   :type x: float | int

   :returns: The computed path length between the soma and the specified point.
   :rtype: float
