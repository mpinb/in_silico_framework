

apical_current_injection
========================


.. Signature -------------------------------

.. py:function:: single_cell_parser.cell_modify_functions.apical_current_injection.apical_current_injection(cell, amplitude=None, delay=None, duration=None, dist=None)


   Inject a current at a given distance from the soma.

   :param cell: The cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param amplitude: The amplitude of the current (nA).
   :type amplitude: float
   :param delay: The delay of the current (ms).
   :type delay: float
   :param duration: The duration of the current (ms).
   :type duration: float
   :param dist: The distance from the soma (um).
                For an apical current injection, this should be the distance from the soma to the apical dendrite.
   :type dist: float

   :returns: The cell with the current injection set up.
   :rtype: :py:class:`~single_cell_parser.cell.Cell`

   .. seealso:: :py:meth:`biophysics_fitting.setup_stim.setup_soma_step`
