

apical_epsp_injection
=====================


.. Signature -------------------------------

.. function:: single_cell_parser.cell_modify_functions.apical_epsp_injection.apical_epsp_injection(cell, dist=None, amplitude=None, delay=None, rise=1.0, decay=5)


   Injects an epsp-shaped current at a certain distance from the soma.

   :param cell: The cell object.
   :type cell: ~single_cell_parser.cell.Cell
   :param dist: The distance from the soma (um).
   :type dist: float
   :param amplitude: The amplitude of the current (nA).
   :type amplitude: float
   :param delay: The delay of the current (ms).
   :type delay: float
   :param rise: The rise time of the epsp (ms).
   :type rise: float
   :param decay: The decay time of the epsp (ms).
   :type decay: float

   :returns: The cell with the current injection set up.
   :rtype: :py:class:`~single_cell_parser.cell.Cell`

   .. seealso:: :py:meth:`biophysics_fitting.setup_stim.setup_apical_epsp_injection`
