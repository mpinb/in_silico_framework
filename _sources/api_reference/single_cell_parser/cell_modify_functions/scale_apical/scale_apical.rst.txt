

scale_apical
============


.. Signature -------------------------------

.. py:function:: single_cell_parser.cell_modify_functions.scale_apical.scale_apical(cell, scale=None, compartment='ApicalDendrite')


   Scale the apical dendrite of a cell.

   :param cell: The cell to scale.
   :type cell: ~single_cell_parser.cell.Cell
   :param scale: The scaling factor.
   :type scale: float
   :param compartment: The compartment to scale.
                       If "ApicalDendrite", the cell is assumed to have sections with label "ApicalDendrite".
                       If "Trunk", the cell is assumed to have ``detailed_labels`` assigned manually, or by :py:meth:`biophysics_fitting.utils.augment_cell_with_detailed_labels`.
                       Currently, only "ApicalDendrite" and "Trunk" are supported compartments.
   :type compartment: str

   :returns: The scaled cell.
   :rtype: :py:class:`~single_cell_parser.cell.Cell`

   :raises ValueError: If the compartment is not "ApicalDendrite" or "Trunk".
