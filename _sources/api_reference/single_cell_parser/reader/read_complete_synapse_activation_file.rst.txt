

read_complete_synapse_activation_file
=====================================


.. Signature -------------------------------

.. py:function:: single_cell_parser.reader.read_complete_synapse_activation_file(fname)


   Reads list of all functional synapses and their activation times.

   This reader also returns "structure label" in addition to the columns of :py:func:`read_synapse_activation_file`.

   .. deprecated::
       This format is now commonly a pandas or dask dataframe.
       They can still be explicitly read with this function
       using Python's ``open()`` and ``read()`` capabilities, but this is not recommended, or efficient.


   :param fname: Filename of a synapse activation file.
                 Such a file can be generated with :py:meth:`single_cell_parser.analyze.synanalysis.comute_synapse_distances_times`.
   :type fname: str

   :returns: A dictionary with cell types as keys and list of synapse locations and activation times, coded as tuples: (synapse ID, soma distance, section ID, point ID, structure label, [t1, t2, ... , tn])
   :rtype: dict
