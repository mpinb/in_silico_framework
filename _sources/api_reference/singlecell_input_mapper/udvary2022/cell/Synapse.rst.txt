.. class:: singlecell_input_mapper.udvary2022.cell.Synapse(edgeID, edgePtID, edgex, preCellType='', postCellType='')

   Bases: :py:obj:`object`
   
   Leightweight dataclass to store basic synapse information.

   Synapses are direct attributes of :class:`~singlecell_input_mapper.singlecell_input_mapper.cell.PySection2` objects,
   which in turn are direct attributes of :class:`~singlecell_input_mapper.singlecell_input_mapper.cell.Cell` objects.
   Contains information on: pre- and postsynaptic cell type, branch ID of postsynaptic cell, branch pt ID,
   and xyz-coordinates of synapse location

   .. seealso::

      This is not the same class as :class:`single_cell_parser.synapse.Synapse`.
      This is a leightweight dataclass specialized for use with :mod:`single_cell_input_mapper.synapse_mapper`,
      and does not contain any methods for NEURON API or synapse activations during simulations.

   :param edgeID: Section ID.
   :type edgeID: ind
   :param edgePtID: Point ID on that section.
   :type edgePtID: int
   :param edgex: Relative position along the section (0-1).
   :type edgex: float
   :param preCellType: Presynaptic cell type. Default: ''.
   :type preCellType: str
   :param postCellType: Postsynaptic cell type. Default: ''.
   :type postCellType: str

   :Attributes:

      .. attribute:: secID

         Section ID.

         :type: int

      .. attribute:: ptID

         Point ID on that section.

         :type: int

      .. attribute:: x

         Relative position along the section (0-1).

         :type: float

      .. attribute:: preCellType

         Presynaptic cell type.

         :type: str

      .. attribute:: preCell

         Presynaptic cell.

         :type: :class:`~singlecell_input_mapper.singlecell_input_mapper.cell.PointCell`

      .. attribute:: postCellType

         Postsynaptic cell type.

         :type: str

      .. attribute:: coordinates

         3D coordinates of the synapse location.

         :type: numpy.ndarray
