

_pt_in_box
==========


.. Signature -------------------------------

.. function:: singlecell_input_mapper.udvary2022.synapse_mapper.SynapseMapper._pt_in_box(pt, box)


   Check if a point is inside a bounding box.

   :param pt: Point to check.
   :type pt: array
   :param box: Bounding box to check against. Box is a length-6 array of format (xmin, xmax, ymin, ymax, zmin, zmax).
   :type box: array

   :returns: True if point is inside bounding box, False otherwise.
   :rtype: bool
