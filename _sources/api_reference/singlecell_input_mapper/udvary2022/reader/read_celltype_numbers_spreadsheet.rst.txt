=================================


.. Signature -------------------------------

.. function:: singlecell_input_mapper.udvary2022.reader.read_celltype_numbers_spreadsheet(fname)


   Reads a spreadsheet with cell type numbers for each anatomical area.

   :param fname: The name of the file to be read
   :type fname: str

   :returns: A dictionary with the following structure: {anatomical_area: {cell_type: number_of_cells, ...}, ...}
   :rtype: dict
