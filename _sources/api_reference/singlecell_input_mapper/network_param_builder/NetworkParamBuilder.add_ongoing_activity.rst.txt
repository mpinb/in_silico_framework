

add_ongoing_activity
====================


.. Signature -------------------------------

.. function:: singlecell_input_mapper.network_param_builder.NetworkParamBuilder.add_ongoing_activity(ongoing_interval_per_ct: collections.abc.Mapping[str, float] = None) -> typing_extensions.Self


   Add :ref:`ongoing_activity_data_format` to the :ref:`network_parameters_format`

   Ongoing activity is background activity, modeled as a Poisson ``"spiketrain"``.
   It is distinct from evoked activity, which is modeled as a ``"pointcell"`` with multiple possible activity distributions
   (see :meth:`~single_cell_parser.network.NetworkMapper._create_pointcell_activities`)

   :param ongoing_interval_per_ct: Mapping between cell types and their ongoing firing interval in ms
   :type ongoing_interval_per_ct: str

   .. seealso:: :meth:`add_activity` for a general-purpose method of adding activity data.
