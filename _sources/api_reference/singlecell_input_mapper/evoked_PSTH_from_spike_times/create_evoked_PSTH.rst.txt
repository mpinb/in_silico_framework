.. Signature -------------------------------

.. function:: singlecell_input_mapper.evoked_PSTH_from_spike_times.create_evoked_PSTH(spikeTimesName, cellType, ongoingRate, outFileName)


   Reads in spike times and creates a PSTH for evoked activity for each whisker.

   :param spikeTimesName: Filepath of the .cluster file containing spike time recordings.
   :type spikeTimesName: str
   :param cellType: Cell type.
   :type cellType: str
   :param ongoingRate: The ongoing firing rate for this cell type.
   :type ongoingRate: float
   :param outFileName: Filename to write to.
   :type outFileName: str
