.. py:function:: singlecell_input_mapper.evoked_PSTH_from_spike_times.scan_directory(path, fnames, suffix)


   Recursively scans a directory for files with a specific suffix.

   :param path: The path of the directory to scan.
   :type path: str
   :param fnames: A list to store the file names.
   :type fnames: list
   :param suffix: The suffix of the files to look for.
   :type suffix: str

   :returns: None. Updates :paramref:`fnames` in place.
