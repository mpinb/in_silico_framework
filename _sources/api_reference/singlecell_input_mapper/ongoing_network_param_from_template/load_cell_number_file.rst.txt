

load_cell_number_file
=====================


.. Signature -------------------------------

.. function:: singlecell_input_mapper.ongoing_network_param_from_template.load_cell_number_file(cellNumberFileName)


   Load the cell number file.

   The cell number file must have the following format::

       Anatomical_area Presynaptic_cell_type   n_cells
       A1      cell_type_1     8
       A1      cell_type_2     14
       ...

   :param cellNumberFileName: Path to the cell number file.
   :type cellNumberFileName: str

   :returns: Dictionary of the form {celltype: {column: nr_of_cells}}
   :rtype: dict

   .. rubric:: Example
      :class: example

   >>> load_cell_number_file(
   ...    'getting_started/example_data/anatomical_constraints/'
   ...    'example_embedding_86_C2_center/'
   ...    'NumberOfConnectedCells.csv'
   ...    )
