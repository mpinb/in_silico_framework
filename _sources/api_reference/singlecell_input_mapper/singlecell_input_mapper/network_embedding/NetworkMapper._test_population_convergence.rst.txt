




NetworkMapper._test_population_convergence
==========================================


.. py:method:: singlecell_input_mapper.singlecell_input_mapper.network_embedding.NetworkMapper._test_population_convergence(nrOfSamples, sampleConnectivityData, postCellName)


   Test how many samples are needed to get a representative sample.

   Tests how many network realizations need to be sampled in order
   to get a reasonable estimate of the variability of connectivity
   parameters.

   :param nrOfSamples: Number of network realizations.
   :type nrOfSamples: int
   :param sampleConnectivityData: List of network realizations.
   :type sampleConnectivityData: list
   :param postCellName: Name of the postsynaptic cell model.
   :type postCellName: str
