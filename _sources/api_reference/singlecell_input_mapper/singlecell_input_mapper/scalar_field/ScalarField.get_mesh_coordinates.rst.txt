




ScalarField.get_mesh_coordinates
================================


.. py:method:: singlecell_input_mapper.singlecell_input_mapper.scalar_field.ScalarField.get_mesh_coordinates(xyz)


   Fetch the mesh index of the voxel containing the point xyz.

   .. warning::

      This method does not perform range checking.
      If :paramref:`xyz` is outside the bounding box, the index will be out of bounds for the :py:attr:`mesh`.

   :param xyz: The 3D coordinates of the point.
   :type xyz: tuple

   :returns: The :py:attr:`mesh` index of the voxel containing the point.
   :rtype: tuple
