.. py:class:: singlecell_input_mapper.singlecell_input_mapper.cell.PointCell(column=None, cellType=None)
   
   Cell object without morphological or biophysical attributes.

   When connecting synapses between postsynaptic and
   presynaptic cells, this class is used for the presynaptic cell.

   :param column: Column ID. Default: None.
   :type column: str
   :param cellType: Cell type. Defalut: None.
   :type cellType: str
