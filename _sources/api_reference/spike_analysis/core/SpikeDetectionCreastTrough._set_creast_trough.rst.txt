




SpikeDetectionCreastTrough._set_creast_trough
=============================================


.. py:method:: spike_analysis.core.SpikeDetectionCreastTrough._set_creast_trough(lim_creast, lim_trough)


   Sets the creast and trough limits based on the given values.

   :param lim_creast: Threshold above which a creast of a spike is detected as such.
   :type lim_creast: float|str
   :param lim_trough: Threshold below which a trough of a spike is detected as such.
   :type lim_trough: float|str

   :raises ValueError: If lim_creast and lim_trough are not both floats or both "minimum" or both "zero".

   .. seealso:: :py:meth:`~spike_analysis.core.SpikeDetectionCreastTrough.get_creast_and_trough_ampltidues_by_bins`

   :returns: None. Sets the :paramref:`lim_creast` and :paramref:`lim_trough` attributes.
