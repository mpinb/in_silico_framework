

strip_st
========


.. Signature -------------------------------

.. py:function:: spike_analysis.core.strip_st(st)


   Get a DataFrame containing only spike times, without metadata.

   Filters out all columns that cannot be converted to an integer.

   :param st: A pandas DataFrame containing spike times as generated by get_st_from_spike_times_and_stim_times

   :returns: A DataFrame containing only spike times.
   :rtype: pd.DataFrame
