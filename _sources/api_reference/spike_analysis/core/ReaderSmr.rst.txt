.. class:: spike_analysis.core.ReaderSmr(path, analogsignal_id=0, stim_times_channel=None, min_rel_time=None, max_rel_time=None)
   
   A class for reading smr-files and accessing stimulus times and voltage traces.

   .. seealso:: :py:class:`spike_analysis.core.ReaderLabView`

   :param path: The path to the smr-file.
   :type path: str
   :param analogsignal_id: The ID of the analog signal to read.
   :type analogsignal_id: int
   :param stim_times_channel: The name of the channel containing the stimulus times.
   :type stim_times_channel: str
   :param min_rel_time: The minimum relative time to include in the voltage traces.
   :type min_rel_time: float
   :param max_rel_time: The maximum relative time to include in the voltage traces.
   :type max_rel_time: float
