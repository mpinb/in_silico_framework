

filter_short_ISIs
=================


.. Signature -------------------------------

.. py:function:: spike_analysis.core.filter_short_ISIs(t, tdelta=0.0)


   Filters out any events that occur in an interval shorter than tdelta.

   :param t: A list containing timepoints of events.
   :type t: list
   :param tdelta: Minimal interval between events. Defaults to 0.
   :type tdelta: float, optional

   :returns: A list containing filtered spike times.
   :rtype: list

   .. rubric:: Example
      :class: example

   >>> filter_short_ISIs([1,2,3,4,5], tdelta=1.5)
   [1, 3, 5]
   >>> filter_short_ISIs([1,2,3,4,5], tdelta=2)
   [1, 3, 5]
