.. class:: spike_analysis.core.STAPlugin_bursts(name='bursts', source='spike_times', event_maxtimes=None, event_names=None)

   Bases: :py:obj:`STAPlugin_TEMPLATE`
   
   SpikeTimeAnalysis (STA) plugin to detect high frequency events (doublet, triplet, ...) that occur within a timewindow.

   .. seealso:: :py:class:`spike_analysis.core.SpikeTimesAnalysis` reads in :paramref:`source`.

   :param name: The name of the plugin. Defaults to 'bursts'.
   :type name: str, optional
   :param source: The :py:class:`~data_base.DataBase` key containing the spike times. Defaults to 'spike_times'.
   :type source: str, optional
   :param event_maxtimes: Dictionary containing the maximum duration of each event type. Default: ``{0:0, 1:10, 2:30}``
   :type event_maxtimes: dict, optional
   :param event_names: Dictionary containing the names of the event types. Default: ``{0: "singlet", 1: "doublet", 2: "triplet"}``
   :type event_names: dict, optional

   :Attributes:
