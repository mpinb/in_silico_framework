

stimulus_interval_filter
========================


.. Signature -------------------------------

.. function:: spike_analysis.core.stimulus_interval_filter(stim_times, period_length=1, offset=0)


   Filters periodic stimuli such that only the first stimulus of each period is retained.

   :param stim_times: A list containing stimulus times.
   :type stim_times: list
   :param period_length: The number of stimuli forming one period. Defaults to 1.
   :type period_length: int, optional
   :param offset: The number of the stimulus in each period to be extracted. Defaults to 0.
   :type offset: int, optional

   :returns: A list containing filtered stimulus times.
   :rtype: list

   .. rubric:: Example
      :class: example

   >>> stimulus_interval_filter([1,2,3,4])
   [1, 2, 3, 4]
   >>> stimulus_interval_filter([1,2,3,4], period_length=2)
   [1, 3]
   >>> stimulus_interval_filter([1,2,3,4], period_length=2, offset=1)
   [2, 4]
