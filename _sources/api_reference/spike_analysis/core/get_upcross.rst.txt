

get_upcross
===========


.. Signature -------------------------------

.. function:: spike_analysis.core.get_upcross(t, v, lim)


   Finds the times and corresponding voltages of upcrossings of a given threshold.

   :param t: Array of time values.
   :type t: numpy.ndarray
   :param v: Array of voltage values.
   :type v: numpy.ndarray
   :param lim: Threshold value.
   :type lim: float

   :returns: Tuple containing arrays of time and voltage values at upcrossings.
   :rtype: Tuple[numpy.ndarray, numpy.ndarray]
