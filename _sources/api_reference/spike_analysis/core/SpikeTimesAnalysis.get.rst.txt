===


.. Signature -------------------------------

.. function:: spike_analysis.core.SpikeTimesAnalysis.get(key)


   Get a key from the database.

   If the key refers to a STAPlugin, the result of the analysis is returned.
   Otherwise, the corresponding value is returned.

   :param key: The name of the event analysis routine.
   :type key: str
