

get_st_from_spike_times_and_stim_times
======================================


.. Signature -------------------------------

.. py:function:: spike_analysis.core.get_st_from_spike_times_and_stim_times(spike_times, stim_times, offset=0, mode='spike_times')


   Computes spike times dataframe based on list of spike times and stimulus times.

   :param spike_times: List of spike times.
   :type spike_times: list
   :param stim_times: List of stimulus times.
   :type stim_times: list
   :param offset: Offset value. Defaults to 0.
   :type offset: float, optional
   :param mode: Mode of computation. Can be 'spike_times' or 'ISIs'. Defaults to 'spike_times'.
   :type mode: str, optional

   :returns: Pandas dataframe. Its format is as follows: One row is one trial. The columns contain the spike times
             and are named in ascending order (0,1,2, ...).
   :rtype: pd.DataFrame

   :raises ValueError: If mode is not 'spike_times' or 'ISIs'.
   :raises ValueError: If offset is not negative.
