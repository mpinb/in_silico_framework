

_sta_input_checker
==================


.. Signature -------------------------------

.. function:: spike_analysis.core._sta_input_checker(t_start, t_end, period)


   Checks if the input is valid.

   :param t_start: Start time.
   :type t_start: float
   :param t_end: End time.
   :type t_end: float
   :param period: Dictionary containing period labels as keys and (period_start, period_end) as values.
   :type period: dict

   :returns: A tuple containing the start time, end time, and period.
   :rtype: tuple

   :raises ValueError: If both :paramref:`period` and either :paramref:`t_start` or :paramref:`t_end` are defined.
   :raises ValueError: If only one of :paramref:`t_start` or :paramref:`t_end` is defined.
