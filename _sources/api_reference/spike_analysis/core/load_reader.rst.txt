

load_reader
===========


.. Signature -------------------------------

.. function:: spike_analysis.core.load_reader(dict_)


   Load a reader object from a dictionary.

   :param dict_: A dictionary containing the attributes of the reader object.
   :type dict_: dict

   :returns: A reader object.
   :rtype: object

   :raises NotImplementedError: If the class of the reader object is not recognized. Currently, only :py:class:`spike_analysis.core.ReaderSmr` is supported.
