.. function:: shared_numpy_store.SharedNumpyStore._get_fname(arr, name)


   Get the filename of an array.

   :param arr: the array
   :type arr: np.ndarray
   :param name: the name of the array

   :returns: the filename that follows the convention of NumpyStore
