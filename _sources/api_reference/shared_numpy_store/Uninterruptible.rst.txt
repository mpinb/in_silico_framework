.. class:: shared_numpy_store.Uninterruptible
   
   Context manager to create an uninterruptible section of code.

   This context manager temporarily ignores ``SIGINT`` and ``SIGTERM`` signals.

   .. warning:: This context manager should be used with caution, as it can lead to unresponsive code (by design).
